windows中使用vim

约 1276 字大约 4 分钟

2025-09-18

在 Windows 的 PowerShell 中使用 vim，有几种方式可以实现，具体取决于你是否已经安装了 Vim 以及你的使用习惯。

✅ 方法一：直接安装 Vim for Windows（推荐）

1. 下载并安装 Vim

Vim 官方提供 Windows 版本：

👉 官网下载地址：https://www.vim.org/download.php#pc

推荐使用：

  • GVim（图形界面 + 命令行）
  • 或使用 Scoop / Chocolatey 安装（更方便）

2. 使用 Scoop 安装 Vim（推荐）

Scoop 是一个 Windows 上的命令行包管理器（Package Manager），它的目标是让在 Windows 上安装、更新和管理开发工具变得像在 Linux 或 macOS 上使用 apt、brew 一样简单。

如果你还没有安装 Scoop，先安装它：

安装 Scoop（包管理器）

$ Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
$ irm get.scoop.sh | iex

安装完成后，你就可以在 PowerShell 中直接使用：

vim myfile.txt

3. 使用 Chocolatey 安装 Vim

如果你使用 Chocolatey：

choco install vim

然后同样可以使用 vim 命令。

✅ 方法二：使用 Windows Terminal + WSL（最佳体验）

如果你经常使用 Linux 工具，推荐安装 WSL（Windows Subsystem for Linux）。

步骤：

  1. 安装 WSL：

    wsl --install

    （会默认安装 Ubuntu）

  2. 重启后，WSL 会自动配置。

  3. 在 PowerShell 中进入 WSL：

    wsl

  4. 在 Linux 环境中使用 Vim：

    vim myfile.txt

✅ 优点：原生 Vim 体验，支持所有插件、语法高亮、tmux、ssh 等。

✅ 方法三：使用 Windows 自带的 vim（如果已安装）

某些 Windows 11 或开发版系统可能已预装 vim，你可以直接在 PowerShell 中尝试：

vim --version

如果返回版本信息，说明已安装，可直接使用。

✅ 方法四：使用 vi 模拟器（不推荐）

PowerShell 本身不带 vim，但你可以通过别名或脚本模拟，但功能非常有限，不推荐用于实际编辑。

🧰 常用 Vim 命令（快速入门）

命令说明
vim filename打开文件
i进入插入模式
Esc退出插入模式
:w保存
:q退出
:wq 或 :x保存并退出
:q!强制退出不保存
:set number显示行号

🔔 注意事项

  • Windows 上的 Vim 可能默认不支持剪贴板、Python 等高级功能，建议使用 WSL 或完整版 GVim。
  • 如果你在 WSL 中编辑文件，确保文件路径在 /mnt/c/... 下才能访问 Windows 文件系统。

✅ 推荐方案总结

需求推荐方式
轻量编辑scoop install vim
专业开发安装 WSL + 在 Linux 中使用 Vim
图形界面下载 GVim
