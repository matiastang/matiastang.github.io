CSS3

CSS3 的新特性大致分为六大类：选择器、边框与圆角、背景与渐变、过渡、变换、动画。本文按这六个知识域逐一整理各属性的语法、参数含义与使用注意点。

注意：在 CSS3 里给元素设置圆角、阴影、变换等属性时，尽管元素的外形位置发生了改变，但元素本身在文档流中占据的大小和位置不变。

一、CSS3 选择器

1. 关系（组合）选择器

  • 子选择器：A > B，选中 A 的直接子元素 B
  • 相邻兄弟选择器：A + B，选中紧挨在 A 后面的同级元素 B
  • 通用兄弟选择器：A ~ B，选中 A 后面所有同级元素 B
  • 群组选择器：A, B，同时选中 A 和 B

2. 属性选择器

语法说明
element[attribute]选中带有 attribute 属性的元素，为其设置样式
element[attribute='value']选中 attribute 属性值完全等于 value 的元素
element[attribute~='value']选中 attribute 属性值中包含独立单词 value 的元素（按空格分隔的单词之一）
element[attribute*='value']选中 attribute 属性值中包含子串 value 的元素
element[attribute^='value']选中 attribute 属性值以 value 开头的元素
element[attribute$='value']选中 attribute 属性值以 value 结尾的元素

PS：注意比较 ~= 和 *= 的区别——~= 要求 value 是一个完整的单词，*= 只要属性值里包含这段字符即可。

3. 伪类选择器

动态伪类

动态伪类并不存在于 HTML 中，只有当用户和网站交互的时候才能体现出来。

  1. 锚点伪类：:link、:visited
  2. 用户行为伪类：:hover、:active、:focus
  3. 目标伪类 :target：点击锚点链接时，对应 id 的元素会显示在视口
  4. checked 状态伪类：checkbox 只能设置宽高，不能设置背景和边框；想自定义外观，需要先用 appearance: none; 清除 input 的默认样式

结构类：nth 选择器

  • :first-child / :last-child：语法 element:first-child，选择属于父元素的首个/最后一个子元素的每个 element 元素。注意 element 指的是子元素。
  • :nth-child(n)：选择某元素下的第 n 个 element 子元素（n 是一个简单的表达式，不能用其他字母代替），括号里还可以传 odd（奇数行）和 even（偶数行）两个关键字。
  • :nth-last-child(n)：匹配属于某元素下的第 n 个 element 子元素，从最后一个子元素开始计数。
  • :nth-of-type(n)：语法 element:nth-of-type(n)，匹配属于父元素的特定类型的第 n 个子元素，element 为指定类型的子元素。
  • :nth-last-of-type(n)：匹配父元素下特定类型的第 n 个子元素，从最后一个开始计数。
  • :first-of-type / :last-of-type：匹配父元素下特定类型的首个/最后一个子元素。
  • :only-child：匹配属于父元素的唯一子元素。
  • :only-of-type：匹配父元素下特定类型的唯一子元素。
  • :empty：匹配没有子元素（包括文本节点）的元素。

否定选择器 :not

  • 定义：匹配非「元素或选择器」的每个元素。
  • 语法：父元素:not(子元素或选择器)
  • 示例：ul:not(span) {}

4. 伪元素

伪元素也可以使用单冒号 : 写法。

伪元素说明
element::first-line对元素的第一行文本设置样式，只能用于块级元素
element::first-letter向文本的首字母设置特殊样式，只能用于块级元素
element::before在元素的内容前面插入新内容，常与 content 配合使用
element::after在元素的内容后面插入新内容，常与 content 配合使用
element::selection设置浏览器中选中文本后的背景色与前景色

伪元素与元素的区别：

  • 无法通过 JS 获取其 DOM
  • 无法通过浏览器开发者工具直接查看
  • 伪元素默认是 inline

使用伪元素注意事项：

  1. 使用 ::before、::after 必须设置 content
  2. 使用 ::before、::after 显示背景图时，一定要用 display 设置为块元素
  3. ::before、::after 设置为 display: inline-block 时，需要再次设置 vertical-align: middle

二、CSS3 边框与圆角

1. 圆角 border-radius

定义：为元素添加圆角边框（块元素、行内块元素、行内元素均可）。

四个单角属性：

  • border-top-left-radius 左上角
  • border-top-right-radius 右上角
  • border-bottom-right-radius 右下角
  • border-bottom-left-radius 左下角

复合属性 border-radius 的属性值规则：

  • 四个值：左上角 右上角 右下角 左下角
  • 三个值：左上角 右上角和左下角 右下角
  • 两个值：左上角和右下角 右上角和左下角
  • 一个值：四个角都生效

border-radius 的属性值还可以由两个参数构成：value1 / value2（用 / 分隔），value1 代表圆角的水平半径，value2 代表圆角的垂直半径。

圆形与椭圆：

  • 一旦使用百分比，参照的是元素本身的宽度与高度
  • 当取 50% 时：宽等于高为圆形，宽不等于高为椭圆形

2. 盒阴影 box-shadow

定义：控制一个或多个下拉阴影的框。

语法：box-shadow: 水平方向偏移量 垂直方向偏移量 模糊程度 扩展程度 颜色 是否内阴影

属性值说明：

  • 偏移量：把元素左上角 (0, 0) 作为基准点，找水平和垂直方向的偏移量
    • 水平：正值向右，负值向左
    • 垂直：正值向下，负值向上
  • 模糊程度：边界模糊，但边界线未动；由边界线向外模糊多少像素（不可为负值）
  • 扩展程度：盒子阴影上下左右都向外扩展多少像素（可为负值）
  • 是否内阴影：默认没有（即默认是外阴影）；加上 inset 后阴影为内阴影

三、CSS3 背景与渐变

1. CSS3 背景

background-image（多重背景）

语法：

background-image: url('1.jpg'), url('2.jpg');

使用逗号把多张图片分开。注意：元素引入多个背景图片时，前面的图片会覆盖后面的图片。

background-clip

定义：指定背景的绘制区域（裁剪）。

语法：background-clip: border-box / padding-box / content-box

  • border-box：背景被裁剪到边框盒（从边框开始绘制背景图片）——默认值
  • padding-box：背景被裁剪到内边距框（从内边距开始绘制背景图片）
  • content-box：背景被裁剪到内容框

background-origin

定义：设置背景图像的原始起始位置。

语法：background-origin: border-box / padding-box / content-box（背景图片坐标原点与这三个值有关）

  • border-box：相对于边框来定位
  • padding-box：相对于内边距来定位
  • content-box：相对于内容框来定位

另外需要了解：background-position 定义背景图片的位置，即水平与垂直方向上的偏移量（参考点）。

background-repeat

定义：设置是否及如何重复背景图像。默认地，背景图像在水平和垂直方向上重复。

  • repeat：默认。背景图像在垂直和水平方向重复
  • repeat-x：背景图像在水平方向重复
  • repeat-y：背景图像在垂直方向重复
  • no-repeat：背景图像仅显示一次
  • inherit：从父元素继承 background-repeat 的设置

background-size

定义：指定背景图像的大小。

语法：background-size: number / % / cover / contain

  • number：宽度 高度（如果只写一个数值，第二个数值默认 auto）
  • 百分比：0% - 100% 之间的任何值，此时的百分比参照于元素的大小
  • cover：将背景图片等比缩放以填满整个容器（最远边）。如果高度先达到对应比例 100%，宽度多出的部分会溢出，具体哪部分溢出取决于定位
  • contain：将背景图片等比缩放至某一边紧贴容器边缘为止（最近边）。如果图片高度比较小，就会有空白区域出现

复合属性 background

定义：在一个声明中设置所有背景属性。

语法：background: color position size repeat origin clip attachment image;

background: #abc center 50% no-repeat content-box content-box fixed url('1.jpg'), url('2.jpg');

2. CSS3 渐变

定义：在两个或多个指定颜色之间显示平稳的过渡。

线性渐变 linear-gradient

定义：沿着一根轴线改变颜色，从起点到终点进行顺序渐变（从一边拉向另一边）。

语法：background: linear-gradient(方向, 开始颜色, 结束颜色)

方向介绍：

/* 1. 方向从上到下（默认） */
background: linear-gradient(red, blue);
/* 2. 方向从左到右 */
background: linear-gradient(to right, red, blue);
/* 3. 对角 */
background: linear-gradient(to right bottom, red, blue);
/* 4. 角度（单位 deg） */
background: linear-gradient(角度, red, blue);

角度说明：0deg 创建一个从下到上的渐变，90deg 创建一个从左到右的渐变。

颜色结点：默认每个颜色均匀分布。

/* 0%~10% 为纯红，10%~20% 红→蓝，20%~30% 蓝→绿，30%~40% 绿→黄，40%~100% 为纯黄 */
background: linear-gradient(red 10%, blue 20%, green 30%, yellow 40%);

/* 0%~10% 为纯红，10%~100% 红→蓝；最后不写具体数值，默认到 100% */
background: linear-gradient(red 10%, blue);

/* 0%~30% 红→蓝；第一个颜色不写位置，默认数值是 0% */
background: linear-gradient(red, blue 30%);

/* 由透明色变为不透明色 */
background: linear-gradient(rgba(255, 0, 0, 0), rgba(255, 0, 0, 1));

重复线性渐变：

background: repeating-linear-gradient(90deg, red 0%, blue 20%);
background: repeating-linear-gradient(90deg, red 0%, blue 10%, red 20%);

注意：把元素的整体宽度看成 100%。

径向渐变 radial-gradient

定义：从起点到终点，颜色从内向外进行圆形渐变。

语法：background: radial-gradient(形状 尺寸, 开始颜色, 结束颜色)

形状分类：

  • circle —— 圆形
  • ellipse —— 椭圆形

注意：当元素的高和宽一样时，无论设置哪个参数，都是圆形。

尺寸大小：

/* closest-side 最近边 */
background: radial-gradient(closest-side circle, red, blue);
/* farthest-side 最远边 */
background: radial-gradient(farthest-side circle, red, blue);
/* closest-corner 最近角 */
background: radial-gradient(closest-corner circle, red, blue);
/* farthest-corner 最远角 */
background: radial-gradient(farthest-corner circle, red, blue);

颜色结点：

background: radial-gradient(circle, red 50%, blue 70%);

注意：此时的百分比指的是圆心到元素最远端的距离。

重复径向渐变：

background: repeating-radial-gradient(red 0%, blue 20%);
background: repeating-radial-gradient(red 0%, blue 10%, red 20%);

四、CSS3 过渡 transition

定义：允许 CSS 的属性值在一定时间区间内平滑地过渡。在鼠标点击、鼠标滑过或对元素的任何改变中触发，并以动画形式圆滑地改变 CSS 属性值。

1. transition-property

  • 定义：设置对象中参与过渡的属性
  • 语法：transition-property: none | all | property
  • 参数说明：
    • none：没有属性改变
    • all：默认值，所有属性都改变
    • property：元素的属性名，如 width、color 等

2. transition-duration

  • 定义：设置对象过渡的持续时间
  • 语法：transition-duration: time
  • 参数说明：规定完成过渡效果需要花费的时间，以秒或毫秒计，默认值 0

3. transition-timing-function

  • 定义：设置对象中过渡的动画类型，即规定过渡效果的速度曲线，允许过渡效果随时间改变速度。
  • 语法：transition-timing-function: linear | ease | ease-in | ease-out | ease-in-out | cubic-bezier(n, n, n, n)
值描述
linear匀速过渡，规定以相同速度开始至结束（等于 cubic-bezier(0,0,1,1)）
ease平滑过渡（慢—快—慢），默认值（等于 cubic-bezier(0.25,0.1,0.25,1)）
ease-in以慢速开始（慢—快，等于 cubic-bezier(0.42,0,1,1)）
ease-out以慢速结束（快—慢，等于 cubic-bezier(0,0,0.58,1)）
ease-in-out以慢速开始和结束（慢—快—慢，等于 cubic-bezier(0.42,0,0.58,1)）
cubic-bezier(n,n,n,n)在 cubic-bezier 函数中定义自己的值，可能的值是 0 至 1 之间的数值

贝塞尔曲线调试工具：https://cubic-bezier.com/#.17,.67,.83,.67

对比实例——为了更好地理解不同的函数值，给五个 div 分别设置不同的速度曲线：

/* 标准写法 */
#div1 { transition-timing-function: linear; }
#div2 { transition-timing-function: ease; }
#div3 { transition-timing-function: ease-in; }
#div4 { transition-timing-function: ease-out; }
#div5 { transition-timing-function: ease-in-out; }

/* 与上例等价，通过 cubic-bezier 来规定速度曲线 */
#div1 { transition-timing-function: cubic-bezier(0, 0, 1, 1); }
#div2 { transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1); }
#div3 { transition-timing-function: cubic-bezier(0.42, 0, 1, 1); }
#div4 { transition-timing-function: cubic-bezier(0, 0, 0.58, 1); }
#div5 { transition-timing-function: cubic-bezier(0.42, 0, 0.58, 1); }

旧版浏览器（如 Firefox 4、旧版 Safari/Chrome/Opera）需要额外写 -moz-、-webkit-、-o- 前缀版本，现代浏览器已无需前缀。

4. transition-delay

  • 定义：设置对象延迟过渡的时间
  • 语法：transition-delay: time
  • 参数说明：指定秒或毫秒数来延迟动画效果的开始，默认是 0

5. transition 复合属性

语法：transition: property duration timing-function delay;

参数说明：过渡时间和延迟时间的顺序不能乱（第一个时间值恒为持续时间）。

五、CSS3 变换 transform

定义：让一个元素在一个坐标系统中变形。该属性包含一系列的变形函数，可以移动、旋转、缩放元素。

语法：transform: none | transform-function，默认值是 none。

1. 2D 变换

rotate() 旋转

  • 定义：通过指定一个角度参数，对元素进行 2D 旋转
  • 语法：transform: rotate(angle)，单位 deg
  • 参数说明：angle 指旋转角度，正数表示顺时针旋转，负数表示逆时针旋转

translate() 平移

  • 定义：根据 X 轴和 Y 轴的位置参数，移动当前元素的位置
  • 分类：
    • translateX() 仅水平方向移动，语法 transform: translateX()，单位 px
    • translateY() 仅垂直方向移动，语法 transform: translateY()，单位 px
    • translate(x, y) 水平方向和垂直方向同时移动，语法 transform: translate(X, Y)，单位 px
  • 注意：如果只写一个参数，第二个默认是 0，也就是只设置了水平方向上的位移

scale() 缩放

  • 定义：设置元素的缩放程度
  • 分类：
    • scaleX() 仅水平方向缩放，无单位
    • scaleY() 仅垂直方向缩放，无单位
    • scale(x, y) 水平和垂直方向同时缩放，无单位

skew() 扭曲/倾斜

  • 定义：设置元素的倾斜状态
  • 分类（单位 deg）：
    • skewX() 仅使元素在水平方向上扭曲变形，正值——逆时针
    • skewY() 仅使元素在垂直方向上扭曲变形，正值——顺时针
    • skew() 使元素在水平和垂直方向上同时扭曲变形
  • 注意：0deg 与 180deg 效果一样

变换基点 transform-origin

  • 定义：元素变换的基准点
  • 语法：transform-origin: 水平方向 垂直方向
  • 参数示例：left top（左上角，四个角均可以）、25% top、50px 50px
  • 默认值：rotate、skew、scale 为几何中心点；translate 为本身位置

2. 3D 变换

  1. 开启 3D 空间：transform-style: preserve-3d;（一般给父元素开启）
  2. 子元素设置 3D 变换效果：
    • rotateX() / rotateY() / rotateZ()：对象在 X/Y/Z 轴上的旋转角度（变换基点：50% 50% 0）
    • translateZ()：对象在 Z 轴上的平移（变换基点：50% 50% 0）
    • scaleZ()：指定对象的 Z 轴缩放（变换基点：50% 50% 0，单独使用意义不大，用于开启 3D 空间）
  3. 设置景深：实现近大远小。父元素、子元素都可以设置：
    • 父元素：perspective: 300px;
    • 子元素：transform: perspective(300px) translateZ(-200px);
    • 注意：景深可选值为大于或等于 0，景深值越大，元素看起来越大；默认值 0 表示没有景深（不能为负值）
  4. 3D 变换基点：默认值 50% 50% 0；transform-origin: top; 关键字表示 (50% 0 0)。注意：立体 3D 盒子的 Z 方向只能使用具体长度，不能使用百分比和关键字
  5. 景深中心点：改变观察者视角
perspective-origin: top;
perspective-origin: top right;
  1. 元素背面可见还是不可见：
backface-visibility: visible; /* 默认值：可见 */
backface-visibility: hidden;  /* 不可见 */

六、CSS3 动画 animation

定义：使元素从一种样式逐渐变化到另外一种样式的效果。

1. @keyframes 关键帧

  • 定义：keyframes 关键帧，用来决定动画变化的关键位置
  • 注意：keyframes 控制的是关键位置，并不是所有位置

语法：

@keyframes animationname {
  keyframes-selector {
    cssStyles;
  }
}
  • animationname：必写项，定义动画的名称
  • keyframes-selector：必写项，动画持续时间的百分比（0% - 100% 之间），或者使用 from 和 to 关键字，from 代表 0%，to 代表 100%

示例：

@keyframes abc {
  from { transform: rotate(0); }
  50%  { transform: rotate(90deg); }
  to   { transform: rotate(360deg); }
}

2. animation 属性

animation-name

  • 设置对象所应用的动画名称
  • 语法：animation-name: keyframename | none
  • 参数说明：keyframename 指定要绑定到选择器的关键帧动画名称

animation-duration

  • 定义：设置对象动画的持续时间
  • 语法：animation-duration: time
  • 参数说明：指定对象播放完成需要花费的时间，默认值是 0

animation-timing-function

  • 定义：设置对象动画的过渡类型，即规定动画的速度曲线，使变化更为平滑
  • 语法：animation-timing-function: value;
  • 参数说明：取值与 transition-timing-function 完全一样（见上文表格），同样基于三次贝塞尔（Cubic Bezier）函数生成速度曲线，取值如下：
值描述
linear动画从头到尾的速度相同
ease默认。动画以低速开始，然后加快，在结束前变慢
ease-in动画以低速开始
ease-out动画以低速结束
ease-in-out动画以低速开始和结束
cubic-bezier(n,n,n,n)在 cubic-bezier 函数中自定义值，可能的值是 0 到 1 的数值

对比实例（与 transition 一致，五个 div 分别设置不同值）：

#div1 { animation-timing-function: linear; }
#div2 { animation-timing-function: ease; }
#div3 { animation-timing-function: ease-in; }
#div4 { animation-timing-function: ease-out; }
#div5 { animation-timing-function: ease-in-out; }

/* 等价的 cubic-bezier 写法 */
#div1 { animation-timing-function: cubic-bezier(0, 0, 1, 1); }
#div2 { animation-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1); }

animation-delay

  • 定义：设置动画的延迟时间
  • 语法：animation-delay: time
  • 参数说明：定义动画开始前等待的时间，以秒或毫秒数计数，默认值是 0

animation-iteration-count

  • 定义：设置对象动画的循环次数
  • 语法：animation-iteration-count: infinite | number
  • 参数说明：number 为数字，默认值是 1；infinite 表示无限循环

animation-direction

  • 定义：设置对象动画是否反向运动
  • 语法：animation-direction: normal | reverse | alternate | alternate-reverse
  • 参数说明：
    • normal：正常方向
    • reverse：反向运动
    • alternate：先正常运动再反向运动，并持续交替运行，需要配合循环属性使用
    • alternate-reverse：先反向运动再正常运动，并持续交替运行，需要配合循环属性使用

animation-play-state

  • 定义：指定对象动画正在运行或已暂停
  • 语法：animation-play-state: paused | running
  • 参数说明：paused 暂停动画；running 默认值，正在运行

示例：鼠标移动到 box 上暂停动画

#box:hover {
  animation-play-state: paused;
}

animation-fill-mode

设置动画结束后的状态：

  • none：默认值。不设置对象动画之外的状态，即 DOM 未进行动画前的状态
  • forwards：设置对象状态为动画结束时的状态（100% 或 to）。当设置 animation-direction 为 reverse 时，动画结束后显示为 keyframes 第一帧
  • backwards：设置对象状态为动画开始时的状态（测试显示为 DOM 未进行动画前的状态）
  • both：设置对象状态为动画结束或开始的状态，结束时状态优先

animation 复合属性（不推荐使用）

语法：

animation: name duration timing-function delay iteration-count direction play-state;
