📋 项目概述

本项目是一个 Keycloak SPI 扩展，用于实现微信 OAuth 登录功能。用户可以通过微信账号登录 Keycloak 管理的应用系统。

核心功能

  • ✅ 微信 OAuth 2.0 授权登录
  • ✅ 自动创建/关联 Keycloak 用户
  • ✅ 支持微信用户信息同步
  • ✅ 支持手机号绑定与短信验证码
  • ✅ 支持开发环境 Mock 模式
  • ✅ 环境变量配置管理
  • ✅ Redis 缓存支持（可选）

技术栈

  • Java: 17
  • Keycloak: 26.4
  • 构建工具: Maven
  • 部署方式: Docker
  • 数据库: MySQL
  • 缓存: Redis（可选）

2. 核心组件说明

2.1 WeChatAuthenticator（认证器）

  • 实现 org.keycloak.authentication.Authenticator 接口
  • 处理微信 OAuth 授权流程
  • 管理用户创建和关联逻辑
  • 首次登录引导手机号绑定与短信校验

2.2 WeChatAuthenticatorFactory（工厂类）

  • 实现 org.keycloak.authentication.AuthenticatorFactory 接口
  • 向 Keycloak 注册认证器
  • 提供元数据和配置信息

2.3 WeChatOAuthService（微信 API 服务）

  • 封装微信 OAuth API 调用
  • 支持多种微信平台（开放平台/公众平台/企业微信）
  • 提供 Mock 实现用于开发测试

2.4 StateCache（状态缓存）

  • 存储 OAuth state 参数（防 CSRF）
  • 提供内存和 Redis 两种实现
  • 支持过期时间管理

2.5 CodeCache（短信验证码缓存）

  • 存储短信验证码与发送频率
  • 支持内存与 Redis 实现
  • 支持验证码过期与重试次数限制

2.6 SmsService（短信服务）

  • 发送手机号验证码
  • 提供 Mock 与阿里云实现

2. 微信平台配置

选择微信平台类型

根据您的应用场景，选择合适的微信平台：

2.1 微信开放平台（推荐用于网页应用）

适用场景: 网站、H5 页面、移动 App

注册步骤:

  1. 访问 微信开放平台
  2. 注册开发者账号（需要企业认证，¥300/年）
  3. 创建网站应用
  4. 填写应用信息：
    • 应用名称：您的应用名称
    • 应用简介：应用描述
    • 应用官网：https://your-domain.com
    • 授权回调域：your-domain.com（重要！）
  5. 等待审核（1-3 个工作日）
  6. 审核通过后获取：
    • AppID: wx1234567890abcdef
    • AppSecret: your_app_secret_32_chars

回调 URL 格式:

https://your-domain.com/realms/{realm-name}/login-actions/authenticate
2.2 微信公众平台（用于公众号内）

适用场景: 微信公众号内的网页

注册步骤:

  1. 访问 微信公众平台
  2. 注册公众号（服务号支持网页授权）
  3. 开发 → 接口权限 → 网页授权
  4. 设置网页授权域名：your-domain.com
  5. 获取：
    • AppID: 在 开发 → 基本配置 中查看
    • AppSecret: 在 开发 → 基本配置 中生成
2.3 企业微信（用于企业内部应用）

适用场景: 企业内部 OA 系统

注册步骤:

  1. 访问 企业微信
  2. 注册企业
  3. 应用管理 → 创建应用
  4. 获取：
    • CorpID: 企业 ID
    • AgentID: 应用 ID
    • Secret: 应用密钥

2.4 开发环境配置（Mock 模式）

如果暂时没有微信平台账号，可以使用 Mock 模式进行开发：

WECHAT_SERVICE_MOCK=true
WECHAT_APP_ID=mock_app_id
WECHAT_APP_SECRET=mock_app_secret
SMS_SERVICE_MOCK=true

Mock 模式下：

  • 不会真实调用微信 API
  • 会模拟返回固定的用户信息
  • 首次登录进入手机号绑定，验证码会打印到日志
  • 所有操作日志会打印到 Keycloak 日志中

创建 src/main/java/com/vectorstory/keycloak/wechat/config/WeChatConfig.java:

package com.vectorstory.keycloak.wechat.config;

/**
 * 微信 OAuth 配置管理
 * 从环境变量读取配置
 */
public class WeChatConfig {

    // 微信平台类型
    public enum PlatformType {
        OPEN,       // 开放平台
        OFFICIAL,   // 公众平台
        WORK        // 企业微信
    }

    private final boolean mock;
    private final PlatformType platformType;
    private final String appId;
    private final String appSecret;
    private final String redirectUri;
    private final String scope;
    private final int stateExpireTime;

    public WeChatConfig() {
        this.mock = "true".equalsIgnoreCase(getEnv("WECHAT_SERVICE_MOCK", "true"));
        this.platformType = parsePlatformType(getEnv("WECHAT_PLATFORM_TYPE", "open"));
        this.appId = getEnv("WECHAT_APP_ID", "");
        this.appSecret = getEnv("WECHAT_APP_SECRET", "");
        this.redirectUri = getEnv("WECHAT_REDIRECT_URI", "");
        this.scope = getEnv("WECHAT_SCOPE", "snsapi_login");
        this.stateExpireTime = Integer.parseInt(getEnv("WECHAT_STATE_EXPIRE_TIME", "300"));
    }

    private String getEnv(String key, String defaultValue) {
        String value = System.getenv(key);
        return (value != null && !value.isEmpty()) ? value : defaultValue;
    }

    private PlatformType parsePlatformType(String type) {
        try {
            return PlatformType.valueOf(type.toUpperCase());
        } catch (IllegalArgumentException e) {
            return PlatformType.OPEN;
        }
    }

    // Getters
    public boolean isMock() { return mock; }
    public PlatformType getPlatformType() { return platformType; }
    public String getAppId() { return appId; }
    public String getAppSecret() { return appSecret; }
    public String getRedirectUri() { return redirectUri; }
    public String getScope() { return scope; }
    public int getStateExpireTime() { return stateExpireTime; }

    /**
     * 获取微信授权 URL
     */
    public String getAuthorizationUrl() {
        switch (platformType) {
            case OPEN:
                return "https://open.weixin.qq.com/connect/qrconnect";
            case OFFICIAL:
                return "https://open.weixin.qq.com/connect/oauth2/authorize";
            case WORK:
                return "https://open.work.weixin.qq.com/wwopen/sso/qrConnect";
            default:
                return "https://open.weixin.qq.com/connect/qrconnect";
        }
    }

    /**
     * 获取 Access Token URL
     */
    public String getAccessTokenUrl() {
        switch (platformType) {
            case WORK:
                return "https://qyapi.weixin.qq.com/cgi-bin/gettoken";
            default:
                return "https://api.weixin.qq.com/sns/oauth2/access_token";
        }
    }

    /**
     * 获取用户信息 URL
     */
    public String getUserInfoUrl() {
        switch (platformType) {
            case WORK:
                return "https://qyapi.weixin.qq.com/cgi-bin/user/getuserinfo";
            default:
                return "https://api.weixin.qq.com/sns/userinfo";
        }
    }
}

package com.vectorstory.keycloak.wechat.cache;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 基于内存的 State 缓存实现
 * 适用于单机开发环境
 */
public class MemoryStateCache implements StateCache {

    private static final Map<String, Long> stateMap = new ConcurrentHashMap<>();

    @Override
    public void saveState(String state, int expireSeconds) {
        long expireTime = System.currentTimeMillis() + (expireSeconds * 1000L);
        stateMap.put(state, expireTime);

        // 清理过期的 state
        cleanExpiredStates();
    }

    @Override
    public boolean validateAndRemoveState(String state) {
        Long expireTime = stateMap.remove(state);
        if (expireTime == null) {
            return false;
        }
        return System.currentTimeMillis() <= expireTime;
    }

    private void cleanExpiredStates() {
        long now = System.currentTimeMillis();
        stateMap.entrySet().removeIf(entry -> entry.getValue() < now);
    }
}

package com.vectorstory.keycloak.wechat.cache;

import com.vectorstory.keycloak.wechat.model.VerificationCode;
import org.jboss.logging.Logger;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 基于内存的短信验证码缓存
 */
public class MemoryCodeCache implements CodeCache {

    private static final Logger logger = Logger.getLogger(MemoryCodeCache.class);

    private static final int CODE_EXPIRY_MINUTES = 5;
    private static final int MAX_ATTEMPTS = 5;
    private static final int SEND_INTERVAL_SECONDS = 60;

    private final Map<String, VerificationCode> codeMap = new ConcurrentHashMap<>();
    private final Map<String, Long> sendTimestamps = new ConcurrentHashMap<>();

    @Override
    public void store(String phone, String code) {
        VerificationCode verificationCode = new VerificationCode(code, System.currentTimeMillis());
        codeMap.put(phone, verificationCode);
        logger.infof("验证码已存储: phone=%s", phone);
    }

    @Override
    public boolean verify(String phone, String inputCode) {
        VerificationCode storedCode = codeMap.get(phone);

        if (storedCode == null) {
            logger.warnf("验证码不存在: phone=%s", phone);
            return false;
        }

        if (storedCode.isExpired(CODE_EXPIRY_MINUTES)) {
            logger.warnf("验证码已过期: phone=%s", phone);
            codeMap.remove(phone);
            return false;
        }

        if (storedCode.isMaxAttemptsExceeded(MAX_ATTEMPTS)) {
            logger.warnf("超过最大尝试次数: phone=%s", phone);
            return false;
        }

        storedCode.incrementAttempts();

        boolean isValid = storedCode.getCode().equals(inputCode);

        if (isValid) {
            logger.infof("验证码验证成功: phone=%s", phone);
            codeMap.remove(phone);
        } else {
            logger.warnf("验证码验证失败: phone=%s, attempts=%d", phone, storedCode.getAttempts());
        }

        return isValid;
    }

    @Override
    public boolean canSendSms(String phone) {
        Long lastSendTime = sendTimestamps.get(phone);

        if (lastSendTime == null) {
            return true;
        }

        long elapsedSeconds = (System.currentTimeMillis() - lastSendTime) / 1000;
        boolean canSend = elapsedSeconds >= SEND_INTERVAL_SECONDS;

        if (!canSend) {
            logger.warnf("发送频率限制: phone=%s, 需等待 %d 秒", phone, SEND_INTERVAL_SECONDS - elapsedSeconds);
        }

        return canSend;
    }

    @Override
    public void recordSmsSent(String phone) {
        sendTimestamps.put(phone, System.currentTimeMillis());
        logger.infof("记录短信发送时间: phone=%s", phone);
    }

    @Override
    public void remove(String phone) {
        codeMap.remove(phone);
        logger.infof("验证码已删除: phone=%s", phone);
    }
}

package com.vectorstory.keycloak.wechat.cache;

import org.jboss.logging.Logger;
import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPool;
import redis.clients.jedis.JedisPoolConfig;

/**
 * 基于 Redis 的短信验证码缓存
 */
public class RedisCodeCache implements CodeCache {

    private static final Logger logger = Logger.getLogger(RedisCodeCache.class);

    private static final int CODE_EXPIRY_SECONDS = 300;
    private static final int SEND_INTERVAL_SECONDS = 60;
    private static final int MAX_ATTEMPTS = 5;

    private static final String CODE_PREFIX = "sms:code:";
    private static final String SEND_PREFIX = "sms:send:";
    private static final String ATTEMPTS_PREFIX = "sms:attempts:";

    private final JedisPool jedisPool;

    public RedisCodeCache() {
        String host = getEnv("REDIS_HOST", "localhost");
        int port = Integer.parseInt(getEnv("REDIS_PORT", "6379"));
        String password = getEnv("REDIS_PASSWORD", null);
        int database = Integer.parseInt(getEnv("REDIS_DATABASE", "0"));

        JedisPoolConfig poolConfig = new JedisPoolConfig();
        poolConfig.setMaxTotal(20);
        poolConfig.setMaxIdle(10);
        poolConfig.setMinIdle(5);
        poolConfig.setTestOnBorrow(true);

        if (password != null && !password.isEmpty()) {
            this.jedisPool = new JedisPool(poolConfig, host, port, 2000, password, database);
        } else {
            this.jedisPool = new JedisPool(poolConfig, host, port, 2000);
        }

        logger.infof("Redis 连接池已初始化: %s:%d, database=%d", host, port, database);
    }

    @Override
    public void store(String phone, String code) {
        try (Jedis jedis = jedisPool.getResource()) {
            String key = CODE_PREFIX + phone;
            jedis.setex(key, CODE_EXPIRY_SECONDS, code);

            String attemptsKey = ATTEMPTS_PREFIX + phone;
            jedis.setex(attemptsKey, CODE_EXPIRY_SECONDS, "0");

            logger.infof("验证码已存储到 Redis: phone=%s", phone);
        } catch (Exception e) {
            logger.errorf(e, "存储验证码到 Redis 失败: phone=%s", phone);
            throw new RuntimeException("Redis 操作失败", e);
        }
    }

    @Override
    public boolean verify(String phone, String inputCode) {
        try (Jedis jedis = jedisPool.getResource()) {
            String key = CODE_PREFIX + phone;
            String storedCode = jedis.get(key);

            if (storedCode == null) {
                logger.warnf("验证码不存在或已过期: phone=%s", phone);
                return false;
            }

            String attemptsKey = ATTEMPTS_PREFIX + phone;
            String attemptsStr = jedis.get(attemptsKey);
            int attempts = attemptsStr != null ? Integer.parseInt(attemptsStr) : 0;

            if (attempts >= MAX_ATTEMPTS) {
                logger.warnf("超过最大尝试次数: phone=%s, attempts=%d", phone, attempts);
                return false;
            }

            jedis.incr(attemptsKey);

            boolean isValid = storedCode.equals(inputCode);

            if (isValid) {
                logger.infof("验证码验证成功: phone=%s", phone);
                jedis.del(key);
                jedis.del(attemptsKey);
            } else {
                logger.warnf("验证码验证失败: phone=%s, attempts=%d", phone, attempts + 1);
            }

            return isValid;
        } catch (Exception e) {
            logger.errorf(e, "验证验证码失败: phone=%s", phone);
            throw new RuntimeException("Redis 操作失败", e);
        }
    }

    @Override
    public boolean canSendSms(String phone) {
        try (Jedis jedis = jedisPool.getResource()) {
            String key = SEND_PREFIX + phone;
            String lastSendTime = jedis.get(key);

            if (lastSendTime == null) {
                return true;
            }

            long lastSend = Long.parseLong(lastSendTime);
            long elapsedSeconds = (System.currentTimeMillis() - lastSend) / 1000;
            boolean canSend = elapsedSeconds >= SEND_INTERVAL_SECONDS;

            if (!canSend) {
                logger.warnf("发送频率限制: phone=%s, 需等待 %d 秒", phone, SEND_INTERVAL_SECONDS - elapsedSeconds);
            }

            return canSend;
        } catch (Exception e) {
            logger.errorf(e, "检查发送频率失败: phone=%s", phone);
            return true;
        }
    }

    @Override
    public void recordSmsSent(String phone) {
        try (Jedis jedis = jedisPool.getResource()) {
            String key = SEND_PREFIX + phone;
            jedis.setex(key, SEND_INTERVAL_SECONDS, String.valueOf(System.currentTimeMillis()));
            logger.infof("记录短信发送时间到 Redis: phone=%s", phone);
        } catch (Exception e) {
            logger.errorf(e, "记录短信发送时间失败: phone=%s", phone);
        }
    }

    @Override
    public void remove(String phone) {
        try (Jedis jedis = jedisPool.getResource()) {
            jedis.del(CODE_PREFIX + phone);
            jedis.del(ATTEMPTS_PREFIX + phone);
            logger.infof("验证码已从 Redis 删除: phone=%s", phone);
        } catch (Exception e) {
            logger.errorf(e, "删除验证码失败: phone=%s", phone);
        }
    }

    private String getEnv(String key, String defaultValue) {
        String value = System.getenv(key);
        return (value != null && !value.isEmpty()) ? value : defaultValue;
    }
}

 */
public class WeChatOAuthServiceImpl implements WeChatOAuthService {

    private static final Logger logger = Logger.getLogger(WeChatOAuthServiceImpl.class);

    private final WeChatConfig config;
    private final OkHttpClient httpClient;
    private final Gson gson;

    public WeChatOAuthServiceImpl() {
        this.config = new WeChatConfig();
        this.httpClient = new OkHttpClient.Builder()
                .connectTimeout(10, TimeUnit.SECONDS)
                .readTimeout(10, TimeUnit.SECONDS)
                .build();
        this.gson = new Gson();

    }

    @Override
    public String buildAuthorizationUrl(String state, String redirectUri) {
        try {
            String baseUrl = config.getAuthorizationUrl();
            String resolvedRedirectUri = resolveRedirectUri(redirectUri);
            String encodedRedirectUri = URLEncoder.encode(resolvedRedirectUri, "UTF-8");

            return String.format("%s?appid=%s&redirect_uri=%s&response_type=code&scope=%s&state=%s#wechat_redirect",
                    baseUrl,
                    config.getAppId(),
                    encodedRedirectUri,
                    config.getScope(),
                    state);
        } catch (UnsupportedEncodingException e) {
            logger.error("构建授权 URL 失败", e);
            throw new RuntimeException("构建授权 URL 失败", e);
        }
    }

    private String resolveRedirectUri(String redirectUri) {
        if (redirectUri != null && !redirectUri.isBlank()) {
            return redirectUri;
        }
        return config.getRedirectUri();
    }

    @Override
    public WeChatAccessToken getAccessToken(String code) throws Exception {
        String url = String.format("%s?appid=%s&secret=%s&code=%s&grant_type=authorization_code",
                config.getAccessTokenUrl(),
                config.getAppId(),
                config.getAppSecret(),
                code);

        logger.debugf("获取 Access Token: code=%s", code);

        Request request = new Request.Builder()
                .url(url)
                .get()
                .build();

        try (Response response = httpClient.newCall(request).execute()) {
            if (!response.isSuccessful()) {
                throw new IOException("获取 Access Token 失败: HTTP " + response.code());
            }

            String body = response.body().string();
            logger.debugf("Access Token 响应: %s", body);

            JsonObject json = gson.fromJson(body, JsonObject.class);

            // 检查错误
            if (json.has("errcode")) {
                int errcode = json.get("errcode").getAsInt();
                String errmsg = json.get("errmsg").getAsString();
                throw new Exception(String.format("微信 API 错误: errcode=%d, errmsg=%s", errcode, errmsg));

            WeChatAccessToken token = new WeChatAccessToken();
            token.setAccessToken(json.get("access_token").getAsString());
            token.setExpiresIn(json.get("expires_in").getAsInt());
            token.setRefreshToken(json.get("refresh_token").getAsString());
            token.setOpenid(json.get("openid").getAsString());
            token.setScope(json.get("scope").getAsString());

            if (json.has("unionid")) {
                token.setUnionid(json.get("unionid").getAsString());
            }

            return token;
        }
    }

/**
 * 阿里云短信服务实现
 */
public class AliyunSmsService implements SmsService {

    private static final Logger logger = Logger.getLogger(AliyunSmsService.class);

    private final Client client;
    private final String signName;
    private final String templateCode;

    public AliyunSmsService() {
        try {
            String accessKeyId = getRequiredEnv("ALIYUN_ACCESS_KEY_ID");
            String accessKeySecret = getRequiredEnv("ALIYUN_ACCESS_KEY_SECRET");
            this.signName = getRequiredEnv("ALIYUN_SMS_SIGN_NAME");
            this.templateCode = getRequiredEnv("ALIYUN_SMS_TEMPLATE_CODE");

            Config config = new Config()
                    .setAccessKeyId(accessKeyId)
                    .setAccessKeySecret(accessKeySecret)
                    .setEndpoint("dysmsapi.aliyuncs.com");

            this.client = new Client(config);

            logger.infof("阿里云短信服务初始化成功: signName=%s, templateCode=%s", signName, templateCode);
        } catch (Exception e) {
            logger.error("阿里云短信服务初始化失败", e);
            throw new RuntimeException("Failed to initialize Aliyun SMS service", e);
        }
    }

    @Override
    public boolean sendVerificationCode(String phoneNumber, String code) {
        try {
            SendSmsRequest request = new SendSmsRequest()
                    .setPhoneNumbers(phoneNumber)
                    .setSignName(signName)
                    .setTemplateCode(templateCode)
                    .setTemplateParam("{\"code\":\"" + code + "\"}");

            SendSmsResponse response = client.sendSms(request);

            String resultCode = response.getBody().getCode();
            boolean success = "OK".equals(resultCode);

            if (success) {
                logger.infof("短信发送成功: phone=%s, code=%s, requestId=%s",
                        phoneNumber, code, response.getBody().getRequestId());
            } else {
                logger.errorf("短信发送失败: phone=%s, code=%s, message=%s",
                        phoneNumber, resultCode, response.getBody().getMessage());
            }

            return success;

        } catch (Exception e) {
            logger.errorf(e, "短信发送异常: phone=%s", phoneNumber);
            return false;
        }
    }

    private String getRequiredEnv(String key) {
        String value = System.getenv(key);
        if (value == null || value.trim().isEmpty()) {
            throw new IllegalStateException("Required environment variable not set: " + key);
        }
        return value.trim();
    }

public class WeChatAuthenticator implements Authenticator {

    private static final Logger logger = Logger.getLogger(WeChatAuthenticator.class);

    private static final String TEMPLATE_LOGIN_BUTTON = "wechat-login-button.ftl";
    private static final String TEMPLATE_PHONE_FORM = "wechat-bind-phone.ftl";
    private static final String TEMPLATE_CODE_FORM = "wechat-bind-code.ftl";

    private static final String FORM_ACTION = "wechatAction";
    private static final String ACTION_LOGIN = "login";
    private static final String ACTION_SEND_CODE = "sendCode";
    private static final String ACTION_VERIFY_CODE = "verifyCode";

    private static final String FORM_PHONE = "phone";
    private static final String FORM_CODE = "code";

    private static final String PARAM_CODE = "code";
    private static final String PARAM_STATE = "state";
    private static final String PARAM_SESSION_CODE = "session_code";
    private static final String PARAM_EXECUTION = "execution";
    private static final String PARAM_CLIENT_ID = "client_id";
    private static final String PARAM_TAB_ID = "tab_id";
    private static final String PARAM_CLIENT_DATA = "client_data";

    private static final String NOTE_WECHAT_OPENID = "WECHAT_OPENID";
    private static final String NOTE_WECHAT_UNIONID = "WECHAT_UNIONID";
    private static final String NOTE_WECHAT_NICKNAME = "WECHAT_NICKNAME";
    private static final String NOTE_WECHAT_AVATAR = "WECHAT_AVATAR";
    private static final String NOTE_WECHAT_GENDER = "WECHAT_GENDER";
    private static final String NOTE_BIND_PHONE = "WECHAT_BIND_PHONE";

    private final WeChatOAuthService oauthService;
    private final StateCache stateCache;
    private final WeChatConfig config;
    private final SmsService smsService;
    private final CodeCache codeCache;
    private final String phoneRegex;
    private final int codeLength;

    public WeChatAuthenticator() {
        this.config = new WeChatConfig();

        this.oauthService = config.isMock()
                ? new MockWeChatOAuthService()
                : new WeChatOAuthServiceImpl();

        boolean useRedis = "true".equalsIgnoreCase(System.getenv("USE_REDIS_CACHE"));
        this.stateCache = useRedis ? new RedisStateCache() : new MemoryStateCache();

        boolean useMockSms = "true".equalsIgnoreCase(System.getenv("SMS_SERVICE_MOCK"));
        this.smsService = useMockSms ? new MockSmsService() : new AliyunSmsService();
        this.codeCache = useRedis ? new RedisCodeCache() : new MemoryCodeCache();

        this.phoneRegex = System.getenv().getOrDefault("PHONE_NUMBER_REGEX", "^1[3-9]\\d{9}$");
        this.codeLength = parseIntEnv("VERIFICATION_CODE_LENGTH", 6);

        logger.infof("微信认证器初始化: mock=%s, stateCache=%s, smsService=%s",
                config.isMock(),
                stateCache.getClass().getSimpleName(),
                smsService.getClass().getSimpleName());
    }

    @Override
    public void authenticate(AuthenticationFlowContext context) {
        Response response = context.form().createForm(TEMPLATE_LOGIN_BUTTON);
        context.challenge(response);
    }

    @Override
    public void action(AuthenticationFlowContext context) {
        MultivaluedMap<String, String> queryParams = context.getHttpRequest().getUri().getQueryParameters();
        String code = queryParams.getFirst(PARAM_CODE);
        String state = queryParams.getFirst(PARAM_STATE);

        if (code != null || state != null) {
            handleCallback(context, code, state);
            return;
        }

        MultivaluedMap<String, String> formData = context.getHttpRequest().getDecodedFormParameters();
        String action = formData.getFirst(FORM_ACTION);

        if (ACTION_LOGIN.equals(action)) {
            if (config.isMock()) {
                handleMockLogin(context);
            } else {
                redirectToWeChat(context);
            }
            return;
        }

        if (ACTION_SEND_CODE.equals(action)) {
            handleSendCode(context, formData);
            return;
        }

        if (ACTION_VERIFY_CODE.equals(action)) {
            handleVerifyCode(context, formData);
            return;
        }

        logger.warnf("未知的操作: %s", action);
        context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                context.form().setError("微信登录失败：请求无效").createForm(TEMPLATE_LOGIN_BUTTON));
    }

    private void redirectToWeChat(AuthenticationFlowContext context) {
        String state = UUID.randomUUID().toString();
        stateCache.saveState(state, config.getStateExpireTime());

        // 使用 Keycloak 提供的 Action URL,它会自动生成正确的 session_code
        // getActionUrl() 返回当前认证流程的 action URL
        String callbackUrl = context.getActionUrl(context.generateAccessCode()).toString();
        String authUrl = oauthService.buildAuthorizationUrl(state, callbackUrl);
        logger.infof("重定向到微信授权页面: %s", authUrl);
        logger.infof("回调地址: %s", callbackUrl);

        Response response = Response.status(302)
                .header("Location", authUrl)
                .build();
        context.challenge(response);
    }

    private String buildCallbackUrl(AuthenticationFlowContext context) {
        return context.getUriInfo().getRequestUriBuilder()
                .replaceQueryParam(PARAM_CODE)
                .replaceQueryParam(PARAM_STATE)
                .build()
                .toString();
    }

    private String resolveRedirectUri(AuthenticationFlowContext context) {
        String configuredRedirect = config.getRedirectUri();
        if (configuredRedirect != null && !configuredRedirect.isBlank()) {
            return mergeLoginParams(configuredRedirect, context.getHttpRequest().getUri().getQueryParameters());
        }
        return buildCallbackUrl(context);
    }

    private String mergeLoginParams(String baseRedirect, MultivaluedMap<String, String> params) {
        UriBuilder builder = UriBuilder.fromUri(baseRedirect);
        copyParam(builder, params, PARAM_SESSION_CODE);
        copyParam(builder, params, PARAM_EXECUTION);
        copyParam(builder, params, PARAM_CLIENT_ID);
        copyParam(builder, params, PARAM_TAB_ID);
        copyParam(builder, params, PARAM_CLIENT_DATA);
        return builder.build().toString();
    }

    private void copyParam(UriBuilder builder, MultivaluedMap<String, String> params, String name) {
        String value = params.getFirst(name);
        if (value != null && !value.isBlank()) {
            builder.replaceQueryParam(name, value);
        }
    }

    private void handleMockLogin(AuthenticationFlowContext context) {
        try {
            WeChatAccessToken token = oauthService.getAccessToken("mock_code");
            WeChatUserInfo userInfo = oauthService.getUserInfo(token.getAccessToken(), token.getOpenid());
            processWeChatUser(context, userInfo);
        } catch (Exception e) {
            logger.error("Mock 微信登录失败", e);
            context.failureChallenge(AuthenticationFlowError.INTERNAL_ERROR,
                    context.form().setError("微信登录失败：" + e.getMessage())
                            .createErrorPage(Response.Status.INTERNAL_SERVER_ERROR));
        }
    }

    private void handleCallback(AuthenticationFlowContext context, String code, String state) {
        logger.infof("微信回调: code=%s, state=%s", code, state);

        if (state == null || !stateCache.validateAndRemoveState(state)) {
            logger.error("State 参数验证失败");
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                    context.form().setError("微信登录失败：state 参数无效")
                            .createErrorPage(Response.Status.BAD_REQUEST));
            return;
        }

        if (code == null || code.isEmpty()) {
            logger.error("授权码为空");
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                    context.form().setError("微信登录失败：授权码无效")
                            .createErrorPage(Response.Status.BAD_REQUEST));
            return;
        }

        try {
            WeChatAccessToken token = oauthService.getAccessToken(code);
            logger.infof("获取 Access Token 成功: openid=%s", token.getOpenid());

            WeChatUserInfo userInfo = oauthService.getUserInfo(token.getAccessToken(), token.getOpenid());
            logger.infof("获取用户信息成功: nickname=%s, openid=%s", userInfo.getNickname(), userInfo.getOpenid());

            processWeChatUser(context, userInfo);
        } catch (Exception e) {
            logger.error("微信登录失败", e);
            context.failureChallenge(AuthenticationFlowError.INTERNAL_ERROR,
                    context.form().setError("微信登录失败：" + e.getMessage())
                            .createErrorPage(Response.Status.INTERNAL_SERVER_ERROR));
        }
    }

    private void processWeChatUser(AuthenticationFlowContext context, WeChatUserInfo userInfo) {
        UserModel user = findUserByUnionId(context, userInfo.getUnionid());

        if (user != null) {
            bindWeChatToUser(user, userInfo);
            context.setUser(user);
            context.success();
            clearWeChatNotes(context.getAuthenticationSession());
            logger.infof("微信登录成功: username=%s, unionid=%s", user.getUsername(), userInfo.getUnionid());
            return;
        }

        storeWeChatNotes(context.getAuthenticationSession(), userInfo);
        Response response = context.form().createForm(TEMPLATE_PHONE_FORM);
        context.challenge(response);
    }

    private void handleSendCode(AuthenticationFlowContext context, MultivaluedMap<String, String> formData) {
        if (!hasWeChatNotes(context.getAuthenticationSession())) {
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                    context.form().setError("微信登录信息已失效，请重新登录")
                            .createForm(TEMPLATE_LOGIN_BUTTON));
            return;
        }

        String phone = formData.getFirst(FORM_PHONE);
        if (!isValidPhone(phone)) {
            Response response = context.form()
                    .setError("手机号格式不正确，请输入正确的手机号")
                    .createForm(TEMPLATE_PHONE_FORM);
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS, response);
            return;
        }

        if (!codeCache.canSendSms(phone)) {
            Response response = context.form()
                    .setError("发送频率过快，请稍后再试")
                    .createForm(TEMPLATE_PHONE_FORM);
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS, response);
            return;
        }

        String code = smsService.generateCode(codeLength);
        boolean sent = smsService.sendVerificationCode(phone, code);

        if (!sent) {
            Response response = context.form()
                    .setError("验证码发送失败，请稍后重试")
                    .createForm(TEMPLATE_PHONE_FORM);
            context.failureChallenge(AuthenticationFlowError.INTERNAL_ERROR, response);
            return;
        }

        codeCache.store(phone, code);
        codeCache.recordSmsSent(phone);
        context.getAuthenticationSession().setAuthNote(NOTE_BIND_PHONE, phone);

        Response response = context.form()
                .setAttribute(FORM_PHONE, phone)
                .createForm(TEMPLATE_CODE_FORM);
        context.challenge(response);
    }

    private void handleVerifyCode(AuthenticationFlowContext context, MultivaluedMap<String, String> formData) {
        AuthenticationSessionModel authSession = context.getAuthenticationSession();
        if (!hasWeChatNotes(authSession)) {
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                    context.form().setError("微信登录信息已失效，请重新登录")
                            .createForm(TEMPLATE_LOGIN_BUTTON));
            return;
        }

        String phone = formData.getFirst(FORM_PHONE);
        if (phone == null || phone.isBlank()) {
            phone = authSession.getAuthNote(NOTE_BIND_PHONE);
        }

        String inputCode = formData.getFirst(FORM_CODE);

        if (phone == null || phone.isBlank() || inputCode == null || inputCode.isBlank()) {
            Response response = context.form()
                    .setAttribute(FORM_PHONE, phone)
                    .setError("验证码不能为空，请重新输入")
                    .createForm(TEMPLATE_CODE_FORM);
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS, response);
            return;
        }

        if (!codeCache.verify(phone, inputCode)) {
            Response response = context.form()
                    .setAttribute(FORM_PHONE, phone)
                    .setError("验证码错误或已过期，请重新获取")
                    .createForm(TEMPLATE_CODE_FORM);
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS, response);
            return;
        }

        WeChatUserInfo userInfo = loadWeChatInfoFromNotes(authSession);
        if (userInfo == null) {
            context.failureChallenge(AuthenticationFlowError.INVALID_CREDENTIALS,
                    context.form().setError("微信登录信息已失效，请重新登录")
                            .createForm(TEMPLATE_LOGIN_BUTTON));
            return;
        }

        UserModel user = findUserByPhone(context, phone);
        if (user == null) {
            user = createUserForPhone(context, phone);
        }

        if (user == null) {
            context.failureChallenge(AuthenticationFlowError.INTERNAL_ERROR,
                    context.form().setError("系统错误，请联系管理员")
                            .createForm(TEMPLATE_PHONE_FORM));
            return;
        }

        bindWeChatToUser(user, userInfo);
        user.setSingleAttribute("phone", phone);
        user.setSingleAttribute("phoneVerified", "true");

        context.setUser(user);
        context.success();
        clearWeChatNotes(authSession);

        logger.infof("手机号绑定成功: username=%s, phone=%s", user.getUsername(), phone);
    }

    private UserModel findUserByUnionId(AuthenticationFlowContext context, String unionid) {
        if (unionid == null || unionid.isBlank()) {
            return null;
        }

        KeycloakSession session = context.getSession();
        RealmModel realm = context.getRealm();
        return session.users().searchForUserByUserAttributeStream(realm, "wechatUnionId", unionid)
                .findFirst()
                .orElse(null);
    }

    private UserModel findUserByPhone(AuthenticationFlowContext context, String phone) {
        KeycloakSession session = context.getSession();
        RealmModel realm = context.getRealm();

        UserModel user = session.users().searchForUserByUserAttributeStream(realm, "phone", phone)
                .findFirst()
                .orElse(null);
        if (user != null) {
            return user;
        }

        return session.users().getUserByUsername(realm, phone);
    }

    private UserModel createUserForPhone(AuthenticationFlowContext context, String phone) {
        KeycloakSession session = context.getSession();
        RealmModel realm = context.getRealm();

        String username = buildUniqueUsername(session, realm, phone);
        try {
            UserModel user = session.users().addUser(realm, username);
            user.setEnabled(true);
            user.setSingleAttribute("phone", phone);
            user.setSingleAttribute("phoneVerified", "true");

            user.addRequiredAction(UserModel.RequiredAction.UPDATE_PROFILE);
            user.addRequiredAction(UserModel.RequiredAction.UPDATE_PASSWORD);

            logger.infof("创建新用户成功: username=%s, phone=%s", user.getUsername(), phone);
            return user;
        } catch (Exception e) {
            logger.errorf(e, "创建用户失败: phone=%s", phone);
            return null;
        }
    }

    private void bindWeChatToUser(UserModel user, WeChatUserInfo userInfo) {
        user.setSingleAttribute("wechatOpenId", userInfo.getOpenid());
        if (userInfo.getUnionid() != null) {
            user.setSingleAttribute("wechatUnionId", userInfo.getUnionid());
        }
        if (userInfo.getNickname() != null) {
            user.setSingleAttribute("wechatNickname", userInfo.getNickname());
        }
        if (userInfo.getHeadimgurl() != null) {
            user.setSingleAttribute("wechatAvatar", userInfo.getHeadimgurl());
        }
        user.setSingleAttribute("wechatGender", userInfo.getSexText());

        if (user.getFirstName() == null || user.getFirstName().isBlank()) {
            user.setFirstName(userInfo.getNickname());
        }
    }

    private void storeWeChatNotes(AuthenticationSessionModel authSession, WeChatUserInfo userInfo) {
        authSession.setAuthNote(NOTE_WECHAT_OPENID, userInfo.getOpenid());
        if (userInfo.getUnionid() != null) {
            authSession.setAuthNote(NOTE_WECHAT_UNIONID, userInfo.getUnionid());
        }
        if (userInfo.getNickname() != null) {
            authSession.setAuthNote(NOTE_WECHAT_NICKNAME, userInfo.getNickname());
        }
        if (userInfo.getHeadimgurl() != null) {
            authSession.setAuthNote(NOTE_WECHAT_AVATAR, userInfo.getHeadimgurl());
        }
        authSession.setAuthNote(NOTE_WECHAT_GENDER, String.valueOf(userInfo.getSex()));
    }

    private boolean hasWeChatNotes(AuthenticationSessionModel authSession) {
        return authSession.getAuthNote(NOTE_WECHAT_OPENID) != null;
    }

    private WeChatUserInfo loadWeChatInfoFromNotes(AuthenticationSessionModel authSession) {
        String openid = authSession.getAuthNote(NOTE_WECHAT_OPENID);
        if (openid == null || openid.isBlank()) {
            return null;
        }

        WeChatUserInfo userInfo = new WeChatUserInfo();
        userInfo.setOpenid(openid);
        userInfo.setUnionid(authSession.getAuthNote(NOTE_WECHAT_UNIONID));
        userInfo.setNickname(authSession.getAuthNote(NOTE_WECHAT_NICKNAME));
        userInfo.setHeadimgurl(authSession.getAuthNote(NOTE_WECHAT_AVATAR));

        String gender = authSession.getAuthNote(NOTE_WECHAT_GENDER);
        if (gender != null && !gender.isBlank()) {
            try {
                userInfo.setSex(Integer.parseInt(gender));
            } catch (NumberFormatException ignored) {
                userInfo.setSex(0);
            }
        }

        return userInfo;
    }

    private void clearWeChatNotes(AuthenticationSessionModel authSession) {
        authSession.removeAuthNote(NOTE_WECHAT_OPENID);
        authSession.removeAuthNote(NOTE_WECHAT_UNIONID);
        authSession.removeAuthNote(NOTE_WECHAT_NICKNAME);
        authSession.removeAuthNote(NOTE_WECHAT_AVATAR);
        authSession.removeAuthNote(NOTE_WECHAT_GENDER);
        authSession.removeAuthNote(NOTE_BIND_PHONE);
    }

    private boolean isValidPhone(String phone) {
        if (phone == null || phone.trim().isEmpty()) {
            return false;
        }
        return phone.trim().matches(phoneRegex);
    }

    private int parseIntEnv(String key, int defaultValue) {
        String value = System.getenv(key);
        if (value == null || value.trim().isEmpty()) {
            return defaultValue;
        }
        try {
            return Integer.parseInt(value.trim());
        } catch (NumberFormatException e) {
            return defaultValue;
        }
    }

    private String buildUniqueUsername(KeycloakSession session, RealmModel realm, String baseUsername) {
        String username = baseUsername;
        int suffix = 1;
        while (session.users().getUserByUsername(realm, username) != null) {
            username = baseUsername + "_" + suffix++;
        }
        return username;
    }

    @Override
    public boolean requiresUser() {
        return false;
    }

    @Override
    public boolean configuredFor(KeycloakSession session, RealmModel realm, UserModel user) {
        return true;
    }

    @Override
    public void setRequiredActions(KeycloakSession session, RealmModel realm, UserModel user) {
    }

    @Override
    public void close() {
    }
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

🐛 常见问题

Q1: 扩展未加载，Keycloak 日志没有微信相关信息

排查步骤:

# 1. 检查 JAR 文件是否存在
ls -la keycloak-wx-authenticator/target/keycloak-wx-authenticator-1.0.0.jar

# 2. 检查容器内挂载
docker compose exec keycloak ls -la /opt/keycloak/providers/

# 3. 检查 SPI 注册文件
unzip -l target/keycloak-wx-authenticator-1.0.0.jar | grep AuthenticatorFactory

# 应该看到：
# META-INF/services/org.keycloak.authentication.AuthenticatorFactory

解决方案:

  • 确保 mvn clean package 编译成功
  • 确保 docker-compose.yml 正确挂载了 JAR 文件
  • 重建容器：docker compose up -d --force-recreate keycloak

Q2: 微信授权后报错 "State 参数无效"

原因: State 缓存失效或不一致

解决方案:

开发环境（单机）：

USE_REDIS_CACHE=false  # 使用内存缓存

生产环境（分布式）：

USE_REDIS_CACHE=true   # 必须使用 Redis

Q3: 获取 Access Token 失败，errcode=40029

错误信息: invalid code

原因: 授权码已被使用或过期

解决方案:

  • 授权码只能使用一次
  • 不要刷新回调页面
  • 检查是否有重复的请求

Q4: 获取用户信息失败，errcode=40001

错误信息: invalid credential, access_token is invalid or not latest

原因: Access Token 无效

解决方案:

  • 检查 AppID 和 AppSecret 是否正确
  • 确认微信平台应用状态正常
  • 检查作用域 scope 是否正确

Q5: 回调 URL 不匹配

错误信息: redirect_uri 参数错误

原因: 回调 URL 未在微信平台配置

解决方案:

  1. 确保域名与微信平台配置一致
  2. 检查 Keycloak KC_HOSTNAME/KC_PROXY（action URL 生成的域名必须正确）
  3. 如使用自定义回调逻辑，再检查 WECHAT_REDIRECT_URI
  4. 微信平台只需要配置域名，不需要完整 URL
    • ✅ 配置: your-domain.com
    • ❌ 不要配置: https://your-domain.com/realms/...

Q6: 本地开发无法测试真实微信登录

解决方案: 使用 ngrok 暴露本地端口

# 启动 ngrok
ngrok http 8081

# 获取公网 URL，例如：https://abc123.ngrok.io

# 如需兼容旧版本可保留
WECHAT_REDIRECT_URI=https://abc123.ngrok.io/realms/vectorstory-test/login-actions/authenticate

# 推荐：让 Keycloak action URL 使用公网域名
KC_HOSTNAME=abc123.ngrok.io

# 在微信平台配置授权回调域
# 域名: abc123.ngrok.io
