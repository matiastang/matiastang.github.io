frp内网穿透

2026-10-29

实现内网穿透的工具有很多，比如ngrok、frp等，这里介绍使用frp实现内网穿透。

注意 文档要看英文文档，英文文档才比较全。

frp 内网穿透完整配置指南

前提条件检查

  • 公网服务器（VPS/云服务器）
  • 域名（例如：abc.com）
  • 本地服务，如Docker部署Keycloak 端口 8081
  • 服务器 SSH 访问权限
  • 域名 DNS 管理权限
  • SSL 证书（可选，推荐）

完整实施流程

服务器端配置

  1. SSH 登录服务器
ssh root@your-server-ip

  1. 创建 frps 配置文件

创建配置目录

$ mkdir -p /etc/frp

查询端口是否被占用

$ lsof -i :7000

编辑配置文件/etc/frp/frps.toml

# frps.toml - frp 服务端配置

# 基础配置
bindPort = 7000                # frp 服务端口
vhostHTTPPort = 80            # HTTP 虚拟主机端口
vhostHTTPSPort = 443          # HTTPS 虚拟主机端口

# Web 管理面板（可选但推荐）
webServer.addr = "0.0.0.0"
webServer.port = 7500
webServer.user = "admin"
webServer.password = "change_me_please"  # ⚠️ 请修改密码

# 安全配置
auth.method = "token"
auth.token = "your_secure_token_here"    # ⚠️ 请设置一个强密码

# 日志配置
log.to = "/var/log/frp/frps.log"
log.level = "info"
log.maxDays = 7

# 性能配置
transport.maxPoolCount = 5
transport.tcpMux = true

重要：请修改以下配置：

  • webServer.password: 改为强密码
  • auth.token: 改为一个复杂的随机字符串（至少 32 位）

配置使用之前记得验证一下，是否正常：

$ ./frps verify -c frps.toml
  1. 创建 systemd 服务文件

在 Linux 系统下，使用 systemd 可以方便地控制 frps 服务端的启动、停止、配置后台运行以及开机自启动。如果系统没有安装 systemd，可先执行：apt install systemd。

$ cd /etc/systemd/system
$ pwd
/etc/systemd/system
$ vim frps.service
[Unit]
Description=Frp Server Service
After=network.target
Wants=network.target

[Service]
Type=simple
User=root
Restart=on-failure
RestartSec=5s
ExecStart=/usr/local/bin/frps -c /etc/frp/frps.toml
ExecReload=/bin/kill -HUP $MAINPID
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target

添加一个脚本，用于管理frps服务

$ cat frpsmanager.sh
#!/bin/sh
# frps service control helper

SERVICE_NAME="${SERVICE_NAME:-frps}"

print_usage() {
  cat <<'EOF'
用法:
  frpsmanager.sh start        启动服务
  frpsmanager.sh stop         停止服务
  frpsmanager.sh restart      重启服务
  frpsmanager.sh status       查看服务状态
  frpsmanager.sh enable       设置开机启动
  frpsmanager.sh disable      取消开机启动
  frpsmanager.sh is-enabled   查看是否已开机启动
  frpsmanager.sh help         查看帮助

可选环境变量:
  SERVICE_NAME  服务名称，默认 frps

示例:
  SERVICE_NAME=frps frpsmanager.sh status
EOF
}

need_root_or_sudo() {
  if [ "$(id -u)" -ne 0 ]; then
    if command -v sudo >/dev/null 2>&1; then
      echo "将使用 sudo 执行 systemctl 操作..."
      SUDO="sudo"
    else
      echo "需要 root 权限或 sudo"
      exit 1
    fi
  else
    SUDO=""
  fi
}

do_systemctl() {
  need_root_or_sudo
  $SUDO systemctl "$@"
}

case "$1" in
  start)
    do_systemctl start "$SERVICE_NAME"
    ;;
  stop)
    do_systemctl stop "$SERVICE_NAME"
    ;;
  restart)
    do_systemctl restart "$SERVICE_NAME"
    ;;
  status)
    systemctl status "$SERVICE_NAME"
    ;;
  enable)
    do_systemctl enable "$SERVICE_NAME"
    ;;
  disable)
    do_systemctl disable "$SERVICE_NAME"
    ;;
  is-enabled)
    systemctl is-enabled "$SERVICE_NAME"
    ;;
  help|-h|--help|"")
    print_usage
    ;;
  *)
    echo "未知命令: $1"
    echo
    print_usage
    exit 1
    ;;
esac
$ chmod +x frpsmanager.sh

$ cat frp.conf
#HTTPS使用SSL访问的配置
server {
    #SSL 默认访问端口号为 443
    listen 443 ssl;

    #请填写绑定证书的域名
    server_name frp.abc.com;

    #请填写证书文件的相对路径或绝对路径
    ssl_certificate /etc/letsencrypt/live/frp.abc.com/fullchain.pem;

    #请填写私钥文件的相对路径或绝对路径
    ssl_certificate_key /etc/letsencrypt/live/frp.abc.com/privkey.pem;

    #缓存SSL握手产生的参数和加密密钥的时长
    ssl_session_timeout 5m;

    #请按照以下协议配置
    ssl_protocols TLSv1.2 TLSv1.3;

    #请按照以下套件配置，配置加密套件，写法遵循 openssl 标准。
    #ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:HIGH:!aNULL:!MD5:!RC4:!DHE;
    ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES128-GCM-SHA256;

    #启用 SSL 会话缓存，避免每次 HTTPS 请求都进行完整的 TLS 握手（耗时且消耗 CPU）
    ssl_session_cache shared:SSL:10m;

    #加密套件优先选择服务器的加密套件
    ssl_prefer_server_ciphers off;

    # frp 管理页面
    location /frp-admin/ {
       # IP 白名单（替换为你的公网 IP）
       allow 171.223.196.63;  # 你的 IP
       deny all;

       # 👇 关键：使用 rewrite 剥离前缀
       rewrite ^/frp-admin/(.*) /$1 break;

       proxy_pass http://127.0.0.1:7500;  # 👈 注意：末尾不要加 /
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto https;

       # 基本认证
       auth_basic "FRP Admin Panel";
       auth_basic_user_file /etc/nginx/.htpasswd;
    }

    # frp 主服务（HTTPS 隧道）
    location / {
       proxy_pass http://127.0.0.1:7443;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto https;

       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
    }
}

4.3 使用 frpc.sh 管理脚本（启动/停止/状态/重启）

frpc操作脚本：

#!/bin/bash

###
 # @Author: matiastang
 # @Date: 2023-12-21 16:43:16
 # @LastEditors: matiastang
 # @LastEditTime: 2023-12-21 16:50:35
 # @FilePath: /HulkPress/Users/matias/matias/MT/MTGithub/tool/frpc/frpc.sh
 # @Description: MacOS 脚本启动停止frpc服务
### 

FRPC_HOME="$HOME/matias/MT/MTGithub/tool/frpc"
client="$FRPC_HOME/frpc"
toml="$FRPC_HOME/frpc.toml"
log="$FRPC_HOME/log"

if [ "$1" = "start" ];then
  nohup $client -c $toml > "$log/nohup_frpc.log" 2>&1 &
  echo "frpc start success"
elif [ "$1" = "status" ];then
   ps aux | grep frpc |  grep -v grep | grep -v $1
   echo "frpc status success"
elif [ "$1" = "reload" ];then
  echo "frpc" `$client reload -c $toml`
elif [ "$1" = "restart" ];then
  ps aux | grep frpc | grep -v grep | grep -v $1 | awk '{print $2}' | xargs kill -9
  rm -rf "$log/frpc.log"
  rm -rf "$log/nohup_frpc.log"
  nohup $client -c $toml > "$log/nohup_frpc.log" 2>&1 &
  echo "frpc restart success"
elif [ "$1" = "stop" ];then
  ps aux | grep frpc | grep -v grep | grep -v $1 | awk '{print $2}' | xargs kill -9
  rm -rf "$log/frpc.log"
  rm -rf "$log/nohup_frpc.log"
  echo "frpc stop success"
else
  other_commands="$client $@"
  $other_commands
fi

常见问题

防病毒软件误删 frpc

一些防病毒软件错误地将 frpc 标记为恶意软件并将其删除。这是因为 frp 是一种能够创建反向代理的网络工具。防病毒软件有时会标记反向代理，因为它们能够绕过防火墙端口限制。如果您使用防病毒软件，则可能需要在防病毒设置中将 frpc 列入白名单/排除，以避免意外隔离/删除。有关更多详细信息，请参阅frp issues 3637。

customDomains 必须与绑定的域名一致

customDomains必须更新为实际绑定/解析的域名，必须要一样，写错了会导致无法访问。

使用 https 访问 frps 仪表盘

在frps.toml文件中添加证书配置：

webServer.tls.certFile = "server.crt"
webServer.tls.keyFile = "server.key"

之后访问https://[serverAddr]:7500即可查看仪表盘。
