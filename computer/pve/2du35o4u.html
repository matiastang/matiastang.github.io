Proxmox VE

约 3046 字大约 10 分钟

2025-02-18

PVE 是 Proxmox VE（Proxmox Virtual Environment）的缩写，是一款基于 Linux 的开源虚拟化平台。它结合了 KVM 虚拟化技术和 LXC 容器技术，提供了强大的服务器虚拟化和容器化管理功能，广泛应用于数据中心、私有云和开发测试环境。

PVE 是多主集群架构，多主集群架构能够让你通过任意节点管理整个集群。基于JavaScript框架（ExtJS）开发的集中Web管理界面不仅能够让你通过GUI界面控制一切功能，而且可以浏览每个节点的历史活动和syslog日志，例如虚拟机备份恢复日志、虚拟机在线迁移日志、HA活动日志等。

PVE 的核心特性

虚拟化支持

KVM 虑拟机：

  • 支持运行完整的虚拟机（Virtual Machines, VMs），每个虚拟机可以运行独立的操作系统。
  • 支持多种操作系统（如 Windows、Linux 等）。

LXC 容器：

  • 基于 Linux 容器技术，提供轻量级的虚拟化解决方案。
  • 容器共享宿主机的操作系统内核，因此启动速度快、资源占用低。

高可用性

  • 支持集群部署，可以通过多台物理服务器实现高可用性（HA）。
  • 提供虚拟机和容器的实时迁移功能（vMotion），确保服务不中断。

存储管理

  • 支持多种存储类型，包括本地磁盘、NAS、SAN、Ceph、ZFS 等。
  • 提供灵活的存储池管理功能，便于分配和优化存储资源。

网络管理

  • 支持复杂的网络配置，包括 VLAN、桥接、绑定等。
  • 可以轻松创建虚拟网络拓扑，满足不同的业务需求。

Web 界面管理

  • 提供直观的 Web 管理界面，简化虚拟机和容器的创建、配置和监控。
  • 支持命令行工具（CLI）和 API，适合自动化运维。

免费与开源

  • PVE 是开源软件，社区版完全免费。
  • 商业版提供额外的功能和技术支持。

PVE 的主要组件

  1. Proxmox VE
  • 核心虚拟化平台，基于 Debian Linux。
  • 提供虚拟机和容器的管理功能。
  1. KVM (Kernel-based Virtual Machine)
  • 内置于 Linux 内核的全虚拟化技术。
  • 支持硬件辅助虚拟化（Intel VT-x 和 AMD-V）。
  1. LXC (Linux Containers)
  • 轻量级容器技术，基于 Linux 内核的命名空间（Namespaces）和控制组（Cgroups）。
  • 提供隔离的运行环境，但共享宿主机内核。
  1. ZFS 和 Ceph
  • 支持先进的存储技术，如 ZFS 和 Ceph，提供高性能和高可靠性存储。

PVE 的典型应用场景

(1) 数据中心虚拟化 使用 PVE 创建和管理虚拟机，提高硬件资源利用率。 支持集群部署，实现高可用性和负载均衡。

(2) 私有云建设 构建私有云基础设施，为用户提供虚拟机和容器服务。 支持动态资源分配和自动化管理。

(3) 开发测试环境 快速创建和销毁虚拟机或容器，用于开发和测试。 支持快照功能，便于回滚到之前的配置。

(4) 容器化应用 使用 LXC 容器部署微服务架构的应用程序。 提供更高的性能和更低的资源消耗。

PVE 的安装与部署

安装可以参考教程2024年PVE8最新安装使用指南|新手入门|安装|优化|Proxmox VE 8.1

系统要求

  • 至少 2 核 CPU，支持硬件虚拟化（VT-x 或 AMD-V）。
  • 至少 8GB 内存（推荐 16GB 或更高）。
  • 至少 30GB 磁盘空间（推荐使用 SSD）。

安装PVE

安装PVE基本步骤如下：

  • 下载PVE ISO镜像文件
  • 将镜像文件刻录到U盘
  • 启动服务器并进入安装界面
  • 按照提示完成基本配置（如主机名、IP 地址、密码等）
  • 安装完成后，通过浏览器访问 Web 管理界面：
https://<服务器IP>:8006

下载 PVE ISO 镜像文件

在PVE官方下载地址下载最新的 ISO 镜像文件。

PVE 扩容（可选）

PVE默认将磁盘分为翁伟两部分，local和local-lvm两部分。

名称类型挂载位置主要用途
local目录存储（ext4）/var/lib/vzISO 镜像、CT 模板、备份文件等
local-lvmLVM-thin 存储LVM thin pool虚拟机硬盘（VM disk）、容器磁盘（CT rootfs）

local 是一个目录存储，用于存储 ISO 镜像、CT 模板、备份文件等。它是一个简单的文件系统，用于存储静态数据。

local-lvm 是 LVM thin pool，它是一个逻辑卷管理（Logical Volume Management，LVM）的存储池，用于存储虚拟机和容器的磁盘数据。LVM thin pool 可以动态地调整大小，以适应存储需求的变化。

对于硬盘比较小的主机，比如我在天虹Mini N10-Pro小主机上加装了一块256GB的长城SSD，比较小，所以需要扩容一下。所谓扩容其实就是合并这两部分，以提高磁盘的使用率，免得出现一个要满了，另外一个还有很多空间的情况。这个看自己的需求，选择性操作。

主要有两步：

  1. 移除local-lvm，这可能会影响PVE的部分快照功能。

在PVE的shell中执行如下命令：

lvremove pve/data

点击y后，执行：

lvextend -l +100%FREE -r pve/root
  1. 在local中添加上原本local-lvm中的选项。

数据中心 –> 存储 –> local-lvm –> 移除，再双击local，把内容里的所有选项都选中。

如上，上面两个步骤就完成了合并。

去除PVE无有效订阅提示（可选项）

pve6.3版本到pve7版本可以执行：

sed -Ezi.bak "s/(Ext.Msg.show\(\{\s+title: gettext\('No valid sub)/void\(\{ \/\/\1/g" /usr/share/javascript/proxmox-widget-toolkit/proxmoxlib.js && systemctl restart pveproxy.service

pve8版本可以执行：

sed -i.backup -z "s/res === null || res === undefined || \!res || res\n\t\t\t.data.status.toLowerCase() \!== 'active'/false/g" /usr/share/javascript/proxmox-widget-toolkit/proxmoxlib.js && systemctl restart pveproxy.service

开启PVE直通功能

shell里输入如下命令：

#若你的CPU为Intel：
sed -i '/^GRUB_CMDLINE_LINUX_DEFAULT/c\GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt pcie_acs_override=downstream"' /etc/default/grub

#若你的CPU为AMD修改为

sed -i '/^GRUB_CMDLINE_LINUX_DEFAULT/c\GRUB_CMDLINE_LINUX_DEFAULT="quiet amd_iommu=on iommu=pt pcie_acs_override=downstream"' /etc/default/grub

增加所需模块，修改文件/etc/modules，输入如下命令：

echo -e "vfio\nvfio_iommu_type1\nvfio_pci\nvfio_virqfd" | tee -a /etc/modules

更新上述配置信息并重启PVE：

update-grub
update-initramfs -u -k all  
reboot

验证是否已开启iommu：

dmesg | grep iommu

看看可直通设备列表：

lspci

PVE 的优势

(1) 性能 基于 KVM 和 LXC 技术，提供高效的虚拟化性能。 支持硬件加速（如 Intel VT-d 和 AMD IOMMU）。

(2) 灵活性 同时支持虚拟机和容器，满足不同场景需求。 支持多种存储和网络配置。

(3) 成本 社区版完全免费，适合个人和中小企业使用。 商业版价格合理，性价比高。

(4) 社区支持 拥有活跃的开源社区，提供丰富的文档和教程。

PVE 的局限性

(1) 系统依赖 PVE 基于 Debian Linux，可能对某些非 Debian 生态的工具支持有限。

(2) 学习曲线 对于初学者来说，可能需要一定时间学习虚拟化和容器化技术。

(3) 商业功能限制 部分高级功能（如增强的备份工具）仅在商业版中提供。

总结

PVE 是一款功能强大且易于使用的虚拟化平台，特别适合需要同时管理虚拟机和容器的场景。无论是个人用户还是企业用户，都可以从 PVE 的高效性能和灵活性中受益。
