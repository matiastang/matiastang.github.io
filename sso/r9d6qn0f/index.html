后端验证 Keycloak 登录状态

核心原理

前端通过 Keycloak 登录后获得 JWT Access Token,后端需要验证这个 token 的有效性。

方式 1: Keycloak Spring Boot Adapter

适用场景: 单体应用或传统 Spring Boot 应用

1. 添加依赖 (Maven)

<dependency>
    <groupId>org.keycloak</groupId>
    <artifactId>keycloak-spring-boot-starter</artifactId>
    <version>26.2.1</version>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

2. 配置 application.yml

keycloak:
  realm: your-realm-name
  auth-server-url: https://your-keycloak-server/
  resource: your-client-id
  credentials:
    secret: your-client-secret  # 如果是 confidential client
  bearer-only: true  # 仅验证 token,不处理登录重定向
  cors: true

3. 创建安全配置

@Configuration
@EnableWebSecurity
public class SecurityConfig extends KeycloakWebSecurityConfigurerAdapter {

    @Autowired
    public void configureGlobal(AuthenticationManagerBuilder auth) {
        auth.authenticationProvider(keycloakAuthenticationProvider());
    }

    @Override
    protected void configure(HttpSecurity http) throws Exception {
        super.configure(http);
        http
            .authorizeRequests()
            .antMatchers("/api/public/**").permitAll()
            .antMatchers("/api/admin/**").hasRole("ADMIN")
            .anyRequest().authenticated()
            .and()
            .cors()
            .and()
            .csrf().disable();
    }

    @Bean
    @Override
    protected SessionAuthenticationStrategy sessionAuthenticationStrategy() {
        return new NullAuthenticatedSessionStrategy();
    }
}

4. 前端发送请求时携带 Token

// 使用项目中的 getToken() 获取有效 token
const token = await getToken();
axios.get('/api/user/profile', {
    headers: {
        'Authorization': `Bearer ${token}`
    }
});

5. 后端获取用户信息

@RestController
@RequestMapping("/api/user")
public class UserController {

    @GetMapping("/profile")
    public UserProfile getProfile(@AuthenticationPrincipal KeycloakPrincipal principal) {
        KeycloakSecurityContext context = principal.getKeycloakSecurityContext();
        AccessToken token = context.getToken();

        String userId = token.getSubject();
        String username = token.getPreferredUsername();
        String email = token.getEmail();
        Set<String> roles = token.getRealmAccess().getRoles();

        return new UserProfile(userId, username, email, roles);
    }
}

方式 2: Spring Security OAuth2 Resource Server

适用场景: 现代化 Spring Boot 应用 (推荐)

1. 添加依赖

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-oauth2-resource-server</artifactId>
</dependency>

2. 配置 application.yml

spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: https://your-keycloak-server/realms/your-realm
          jwk-set-uri: https://your-keycloak-server/realms/your-realm/protocol/openid-connect/certs

3. 安全配置

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/public/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt.jwtAuthenticationConverter(jwtConverter()))
            )
            .cors()
            .and()
            .csrf().disable();

        return http.build();
    }

    @Bean
    public JwtAuthenticationConverter jwtConverter() {
        JwtGrantedAuthoritiesConverter authoritiesConverter = new JwtGrantedAuthoritiesConverter();
        authoritiesConverter.setAuthoritiesClaimName("realm_access.roles");
        authoritiesConverter.setAuthorityPrefix("ROLE_");

        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(authoritiesConverter);
        return converter;
    }
}

4. 获取用户信息

@RestController
@RequestMapping("/api/user")
public class UserController {

    @GetMapping("/profile")
    public UserProfile getProfile(@AuthenticationPrincipal Jwt jwt) {
        String userId = jwt.getSubject();
        String username = jwt.getClaim("preferred_username");
        String email = jwt.getClaim("email");
        List<String> roles = jwt.getClaim("realm_access.roles");

        return new UserProfile(userId, username, email, roles);
    }
}

方式 3: 微服务网关统一验证

适用场景: 微服务架构,使用 Spring Cloud Gateway

1. 网关配置

spring:
  cloud:
    gateway:
      routes:
        - id: user-service
          uri: lb://user-service
          predicates:
            - Path=/api/user/**
          filters:
            - TokenRelay  # 转发 token
  security:
    oauth2:
      client:
        provider:
          keycloak:
            issuer-uri: https://your-keycloak-server/realms/your-realm
        registration:
          keycloak:
            client-id: your-gateway-client

2. 下游服务只需解析 JWT

// 从 Header 获取 token 并解析 (网关已验证有效性)
@RestController
@RequestMapping("/api/user")
public class UserController {

    @GetMapping("/profile")
    public UserProfile getProfile(@RequestHeader("Authorization") String authHeader) {
        String token = authHeader.replace("Bearer ", "");
        DecodedJWT jwt = JWT.decode(token);

        String userId = jwt.getSubject();
        String username = jwt.getClaim("preferred_username").asString();

        return new UserProfile(userId, username);
    }
}

扩展登录方式

Keycloak 默认支持的登录方式

  • 用户名/密码
  • 邮箱/密码
  • 社交登录 (通过 Identity Provider)
  • OTP (基于时间的一次性密码,如 Google Authenticator)

集成手机验证码登录

Keycloak 官方不直接支持手机验证码,需要自定义开发 Authenticator SPI。

实现步骤

1. 创建 Maven 项目
<dependency>
    <groupId>org.keycloak</groupId>
    <artifactId>keycloak-server-spi</artifactId>
    <version>26.2.1</version>
</dependency>
<dependency>
    <groupId>org.keycloak</groupId>
    <artifactId>keycloak-server-spi-private</artifactId>
    <version>26.2.1</version>
</dependency>
2. 实现 Authenticator 接口
public class SmsAuthenticator implements Authenticator {

    @Override
    public void authenticate(AuthenticationFlowContext context) {
        // 生成 6 位验证码
        String code = String.format("%06d", new Random().nextInt(999999));

        // 获取手机号 (从用户属性或表单)
        String phoneNumber = getPhoneNumber(context);

        // 调用短信服务发送验证码 (集成阿里云、腾讯云等)
        sendSms(phoneNumber, code);

        // 将验证码存储到 session
        context.getAuthenticationSession().setAuthNote("sms_code", code);
        context.getAuthenticationSession().setAuthNote("sms_code_time",
            String.valueOf(System.currentTimeMillis()));

        // 显示验证码输入页面
        Response challenge = context.form()
            .setAttribute("phoneNumber", phoneNumber)
            .createForm("sms-code-form.ftl");
        context.challenge(challenge);
    }

    @Override
    public void action(AuthenticationFlowContext context) {
        // 验证用户输入的验证码
        String enteredCode = context.getHttpRequest()
            .getDecodedFormParameters()
            .getFirst("sms_code");

        String expectedCode = context.getAuthenticationSession()
            .getAuthNote("sms_code");

        String codeTime = context.getAuthenticationSession()
            .getAuthNote("sms_code_time");

        // 检查验证码是否过期 (5 分钟)
        long elapsed = System.currentTimeMillis() - Long.parseLong(codeTime);
        if (elapsed > 5 * 60 * 1000) {
            context.failureChallenge(
                AuthenticationFlowError.EXPIRED_CODE,
                context.form().setError("expiredSmsCode").createForm("sms-code-form.ftl")
            );
            return;
        }

        if (enteredCode != null && enteredCode.equals(expectedCode)) {
            context.success();
        } else {
            context.failureChallenge(
                AuthenticationFlowError.INVALID_CREDENTIALS,
                context.form().setError("invalidSmsCode").createForm("sms-code-form.ftl")
            );
        }
    }

    @Override
    public boolean requiresUser() {
        return true;
    }

    @Override
    public boolean configuredFor(KeycloakSession session, RealmModel realm, UserModel user) {
        return user.getFirstAttribute("phone") != null;
    }

    @Override
    public void setRequiredActions(KeycloakSession session, RealmModel realm, UserModel user) {
        // 可以设置必需操作,例如要求用户绑定手机号
    }

    @Override
    public void close() {
    }

    private String getPhoneNumber(AuthenticationFlowContext context) {
        // 从用户属性获取手机号
        UserModel user = context.getUser();
        if (user != null) {
            return user.getFirstAttribute("phone");
        }
        // 或从表单获取
        return context.getHttpRequest().getDecodedFormParameters().getFirst("phone");
    }

    private void sendSms(String phoneNumber, String code) {
        // 集成短信服务商 API
        // 示例: 阿里云短信服务
        try {
            // AliyunSmsClient.send(phoneNumber, "您的验证码是: " + code);
            System.out.println("发送短信到 " + phoneNumber + ": " + code);
        } catch (Exception e) {
            throw new RuntimeException("发送短信失败", e);
        }
    }
}

集成微信扫码登录

Keycloak 支持通过 Identity Provider (IdP) 集成第三方登录。

实现步骤

1. 在微信开放平台注册应用
  1. 访问 https://open.weixin.qq.com/
  2. 创建网站应用
  3. 获取 AppID 和 AppSecret
  4. 配置授权回调域: https://your-keycloak-server/realms/your-realm/broker/wechat/endpoint
2. 开发微信 Identity Provider 扩展

由于 Keycloak 没有内置微信支持,需要自定义开发。

参考社区项目: https://github.com/jeff-tian/keycloak-services-social-weixin

核心代码实现:

public class WeChatIdentityProvider extends AbstractOAuth2IdentityProvider<WeChatConfig> {

    public static final String AUTH_URL = "https://open.weixin.qq.com/connect/qrconnect";
    public static final String TOKEN_URL = "https://api.weixin.qq.com/sns/oauth2/access_token";
    public static final String USER_INFO_URL = "https://api.weixin.qq.com/sns/userinfo";

    public WeChatIdentityProvider(KeycloakSession session, WeChatConfig config) {
        super(session, config);
    }

    @Override
    protected String getDefaultScopes() {
        return "snsapi_login";
    }

    @Override
    protected BrokeredIdentityContext extractIdentityFromProfile(
        EventBuilder event, JsonNode profile) {

        // 使用 unionid 作为唯一标识
        BrokeredIdentityContext user = new BrokeredIdentityContext(
            getJsonProperty(profile, "unionid")
        );

        user.setUsername(getJsonProperty(profile, "nickname"));
        user.setFirstName(getJsonProperty(profile, "nickname"));

        // 保存微信信息到用户属性
        user.setUserAttribute("wechat_unionid", getJsonProperty(profile, "unionid"));
        user.setUserAttribute("wechat_openid", getJsonProperty(profile, "openid"));
        user.setUserAttribute("avatar", getJsonProperty(profile, "headimgurl"));
        user.setUserAttribute("wechat_nickname", getJsonProperty(profile, "nickname"));

        user.setIdpConfig(getConfig());
        user.setIdp(this);

        return user;
    }

    @Override
    protected String getUserInfoUrl() {
        return USER_INFO_URL;
    }

    protected class Endpoint extends OAuth2IdentityProvider<WeChatConfig>.Endpoint {
        public Endpoint(AuthenticationCallback callback, RealmModel realm, EventBuilder event) {
            super(callback, realm, event);
        }

        @Override
        public SimpleHttp generateTokenRequest(String authorizationCode) {
            return SimpleHttp.doGet(TOKEN_URL, session)
                .param("appid", getConfig().getClientId())
                .param("secret", getConfig().getClientSecret())
                .param("code", authorizationCode)
                .param("grant_type", "authorization_code");
        }
    }
}

微信用户信息保存

问题分析

微信登录时会返回 unionid 和 openid,这两个 ID 非常重要:

  • unionid: 同一用户在同一开放平台下的所有应用中的唯一标识
  • openid: 用户在单个公众号/小程序中的唯一标识

仅使用 Mapper 映射到标准字段是不够的,需要使用 User Attributes (用户自定义属性) 保存。

解决方案

1. 通过 Identity Provider 自动保存

参考上面"集成微信扫码登录"部分的第 7 步和第 8 步。

2. 在后端获取微信信息

Spring Boot 代码:

@RestController
@RequestMapping("/api/user")
public class UserController {

    @GetMapping("/profile")
    public UserProfile getProfile(@AuthenticationPrincipal Jwt jwt) {
        String userId = jwt.getSubject();
        String username = jwt.getClaim("preferred_username");
        String email = jwt.getClaim("email");

        // 获取微信自定义属性
        String wechatUnionId = jwt.getClaim("wechat_unionid");
        String wechatOpenId = jwt.getClaim("wechat_openid");
        String avatar = jwt.getClaim("avatar");

        return UserProfile.builder()
            .userId(userId)
            .username(username)
            .email(email)
            .wechatUnionId(wechatUnionId)
            .wechatOpenId(wechatOpenId)
            .avatar(avatar)
            .build();
    }
}

用户体系集成策略

核心概念理解

Realm vs Client

  • Realm: 用户的实际存储位置,用户属于 Realm
  • Client: 应用程序,只是访问用户的入口
  • User ID (sub): 在整个 Realm 内唯一且不变

重要结论: 用户 ID 与 Client 无关,只与 Realm 相关。

同一个用户在同一 Realm 下:
- 通过 Client A 登录: sub = "a1b2c3d4-..."
- 通过 Client B 登录: sub = "a1b2c3d4-..."  (相同)

同一个用户在不同 Realm 下:
- Realm1 中: sub = "a1b2c3d4-..."
- Realm2 中: sub = "x9y8z7w6-..."  (不同)

策略 1: 直接使用 Keycloak User ID

适用场景: 新项目或可以迁移数据的项目 ✅ 推荐

数据库设计

-- 用户业务表
CREATE TABLE biz_user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    keycloak_user_id VARCHAR(36) NOT NULL UNIQUE COMMENT 'Keycloak 的 sub',
    keycloak_username VARCHAR(255) COMMENT '用户名 (冗余存储)',
    nickname VARCHAR(100),
    phone VARCHAR(20),
    wechat_unionid VARCHAR(64) UNIQUE COMMENT '微信 unionid',
    wechat_openid VARCHAR(64) COMMENT '微信 openid',
    avatar VARCHAR(500) COMMENT '头像 URL',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_keycloak_user_id (keycloak_user_id),
    INDEX idx_wechat_unionid (wechat_unionid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='业务用户表';

-- 订单表
CREATE TABLE orders (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL COMMENT '关联 biz_user.id',
    order_no VARCHAR(50),
    amount DECIMAL(10, 2),
    status VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (user_id) REFERENCES biz_user(id),
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';

后端实现

@Service
public class UserService {

    @Autowired
    private BizUserRepository bizUserRepository;

    /**
     * 用户首次登录时自动创建业务用户记录
     */
    public BizUser getOrCreateUser(Jwt jwt) {
        String keycloakUserId = jwt.getSubject();

        return bizUserRepository.findByKeycloakUserId(keycloakUserId)
            .orElseGet(() -> {
                BizUser newUser = new BizUser();
                newUser.setKeycloakUserId(keycloakUserId);
                newUser.setKeycloakUsername(jwt.getClaim("preferred_username"));
                newUser.setNickname(jwt.getClaim("name"));

                // 如果有微信信息
                String wechatUnionId = jwt.getClaim("wechat_unionid");
                if (wechatUnionId != null) {
                    newUser.setWechatUnionId(wechatUnionId);
                    newUser.setWechatOpenId(jwt.getClaim("wechat_openid"));
                    newUser.setAvatar(jwt.getClaim("avatar"));
                }

                return bizUserRepository.save(newUser);
            });
    }
}

账号绑定服务

@Service
public class AccountBindService {

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private UserKeycloakMappingRepository mappingRepository;

    @Autowired
    private PasswordEncoder passwordEncoder;

    @Autowired
    private SmsService smsService;

    /**
     * 场景 1: 老用户首次用 Keycloak 登录,需要绑定原账号
     */
    public void bindExistingAccount(Jwt jwt, String legacyUsername, String legacyPassword) {
        // 1. 验证原账号密码
        User legacyUser = userRepository.findByUsername(legacyUsername)
            .orElseThrow(() -> new BusinessException("原账号不存在"));

        if (!passwordEncoder.matches(legacyPassword, legacyUser.getPassword())) {
            throw new BusinessException("密码错误");
        }

        // 2. 创建映射关系
        UserKeycloakMapping mapping = new UserKeycloakMapping();
        mapping.setLegacyUserId(legacyUser.getId());
        mapping.setKeycloakUserId(jwt.getSubject());
        mapping.setBindType(BindType.PASSWORD);

        mappingRepository.save(mapping);
    }

    /**
     * 场景 2: 用户通过微信登录,绑定到已有手机号
     */
    public void bindWechatToPhone(Jwt jwt, String phone, String smsCode) {
        // 1. 验证短信验证码
        if (!smsService.verify(phone, smsCode)) {
            throw new BusinessException("验证码错误");
        }

        // 2. 查找现有账号
        User legacyUser = userRepository.findByPhone(phone)
            .orElseThrow(() -> new BusinessException("手机号未注册"));

        // 3. 创建映射
        UserKeycloakMapping mapping = new UserKeycloakMapping();
        mapping.setLegacyUserId(legacyUser.getId());
        mapping.setKeycloakUserId(jwt.getSubject());
        mapping.setWechatUnionid(jwt.getClaim("wechat_unionid"));
        mapping.setWechatOpenid(jwt.getClaim("wechat_openid"));
        mapping.setBindType(BindType.WECHAT);

        mappingRepository.save(mapping);
    }

    /**
     * 场景 3: 通过微信 unionid 自动绑定
     */
    public Long bindByWechatUnionId(String wechatUnionId, String keycloakUserId) {
        // 查找是否已有用户绑定了这个 unionid
        return mappingRepository.findByWechatUnionid(wechatUnionId)
            .map(UserKeycloakMapping::getLegacyUserId)
            .orElse(null);
    }

    /**
     * 获取业务用户 ID
     */
    public Long getLegacyUserId(String keycloakUserId) {
        return mappingRepository.findByKeycloakUserId(keycloakUserId)
            .map(UserKeycloakMapping::getLegacyUserId)
            .orElse(null);
    }
}

拦截器处理未绑定用户

@Component
public class UserContextInterceptor implements HandlerInterceptor {

    @Autowired
    private AccountBindService bindService;

    @Autowired
    private UserRepository userRepository;

    @Override
    public boolean preHandle(HttpServletRequest request,
                            HttpServletResponse response,
                            Object handler) throws Exception {
        Authentication auth = SecurityContextHolder.getContext().getAuthentication();
        if (auth != null && auth.getPrincipal() instanceof Jwt) {
            Jwt jwt = (Jwt) auth.getPrincipal();
            String keycloakUserId = jwt.getSubject();

            // 尝试通过微信 unionid 自动绑定
            String wechatUnionId = jwt.getClaim("wechat_unionid");
            if (wechatUnionId != null) {
                Long legacyUserId = bindService.bindByWechatUnionId(wechatUnionId, keycloakUserId);
                if (legacyUserId != null) {
                    User user = userRepository.findById(legacyUserId).orElse(null);
                    UserContextHolder.setCurrentUser(user);
                    return true;
                }
            }

            Long legacyUserId = bindService.getLegacyUserId(keycloakUserId);
            if (legacyUserId == null) {
                // 用户未绑定,返回特殊状态码,前端跳转到绑定页面
                response.setStatus(HttpStatus.PRECONDITION_REQUIRED.value());
                response.getWriter().write("{\"error\":\"ACCOUNT_NOT_BOUND\",\"message\":\"请绑定已有账号\"}");
                return false;
            }

            User user = userRepository.findById(legacyUserId).orElse(null);
            UserContextHolder.setCurrentUser(user);
        }
        return true;
    }
}

策略 3: 数据迁移方案

适用场景: 决定完全迁移到 Keycloak

迁移服务

@Service
public class UserMigrationService {

    @Autowired
    private Keycloak keycloakAdmin;  // Keycloak Admin Client

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private UserKeycloakMappingRepository mappingRepository;

    @Value("${keycloak.realm}")
    private String realm;

    public void migrateUsers() {
        List<User> legacyUsers = userRepository.findAll();

        for (User legacyUser : legacyUsers) {
            try {
                // 1. 在 Keycloak 中创建用户
                UserRepresentation kcUser = new UserRepresentation();
                kcUser.setUsername(legacyUser.getUsername());
                kcUser.setEmail(legacyUser.getEmail());
                kcUser.setEnabled(true);
                kcUser.setEmailVerified(legacyUser.getEmailVerified());

                // 添加自定义属性
                Map<String, List<String>> attributes = new HashMap<>();
                attributes.put("legacy_user_id", Arrays.asList(legacyUser.getId().toString()));
                attributes.put("phone", Arrays.asList(legacyUser.getPhone()));
                kcUser.setAttributes(attributes);

                Response response = keycloakAdmin.realm(realm)
                    .users()
                    .create(kcUser);

                if (response.getStatus() != 201) {
                    log.error("Failed to create user {}: {}",
                        legacyUser.getUsername(), response.getStatusInfo());
                    continue;
                }

                String keycloakUserId = getCreatedId(response);

                // 2. 设置临时密码 (要求用户首次登录修改)
                CredentialRepresentation credential = new CredentialRepresentation();
                credential.setType(CredentialRepresentation.PASSWORD);
                credential.setValue(generateTempPassword());  // 生成临时密码
                credential.setTemporary(true);

                keycloakAdmin.realm(realm)
                    .users()
                    .get(keycloakUserId)
                    .resetPassword(credential);

                // 3. 保存映射关系
                UserKeycloakMapping mapping = new UserKeycloakMapping();
                mapping.setLegacyUserId(legacyUser.getId());
                mapping.setKeycloakUserId(keycloakUserId);
                mapping.setBindType(BindType.PASSWORD);
                mappingRepository.save(mapping);

                log.info("Migrated user: {} -> {}", legacyUser.getUsername(), keycloakUserId);

                // 发送通知邮件告知用户临时密码
                // emailService.sendTempPassword(legacyUser.getEmail(), tempPassword);

            } catch (Exception e) {
                log.error("Failed to migrate user: {}", legacyUser.getUsername(), e);
            }
        }
    }

    private String getCreatedId(Response response) {
        String location = response.getHeaderString("Location");
        return location.substring(location.lastIndexOf('/') + 1);
    }

    private String generateTempPassword() {
        // 生成 8 位随机密码
        String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
        Random random = new Random();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 8; i++) {
            sb.append(chars.charAt(random.nextInt(chars.length())));
        }
        return sb.toString();
    }
}

Realm 和 Client 的考虑

是否需要考虑 Realm?

需要,但只在架构设计阶段考虑一次:

1. 单 Realm 策略 (推荐大多数场景)

Realm: my-company
  ├── Users (所有用户)
  ├── Client: web-app (Web 前端)
  ├── Client: mobile-app (移动端)
  ├── Client: backend-api (后端服务)
  └── Client: admin-portal (管理后台)
  • 所有用户在同一个 Realm
  • 不同应用作为不同 Client
  • 用户在各个 Client 间共享,user ID 保持一致

2. 多 Realm 策略 (适用于多租户 SaaS)

Keycloak
  ├── Realm: tenant-a
  │     └── Users (租户 A 的用户)
  ├── Realm: tenant-b
  │     └── Users (租户 B 的用户)
  └── Realm: tenant-c
        └── Users (租户 C 的用户)
  • 每个租户一个 Realm
  • 用户数据完全隔离
  • 需要在业务代码中区分 Realm

是否需要考虑 Client?

在关联用户时不需要考虑 Client,原因:

// 无论用户通过哪个 Client 登录,获取到的 user ID 都相同
String userId = jwt.getSubject();  // 在同一 Realm 下永远一致

// 但如果需要区分用户来源 (可选)
String clientId = jwt.getClaim("azp");  // authorized party
if ("mobile-app".equals(clientId)) {
    // 移动端登录的用户
} else if ("web-app".equals(clientId)) {
    // Web 端登录的用户
}

方案选择总结

场景推荐策略是否考虑 Realm是否考虑 Client
新项目策略 1: 直接用 Keycloak User ID是 (选一个)否
已有用户体系策略 2: 建立映射表是 (选一个)否
需要完全迁移策略 3: 数据迁移 + 映射表是 (选一个)否
多租户 SaaS多 Realm + 映射表是 (动态)否

最佳实践

  1. 数据库设计

    • 在 biz_user 表中保存 keycloak_user_id、wechat_unionid、wechat_openid
    • 业务关联只使用自增主键 id

  2. 自动关联

    • 用户首次登录时自动创建业务记录
    • 使用拦截器自动将 Keycloak 用户映射到业务用户

  3. 微信绑定

    • 优先使用 wechat_unionid 作为唯一标识
    • 在 Keycloak User Attributes 中保存微信信息
    • 通过 Protocol Mapper 将微信信息加入 JWT Token

  4. 后端验证方式选择

    • 单体应用: Keycloak Adapter
    • 现代 Spring Boot: OAuth2 Resource Server ✅ 推荐
    • 微服务架构: 网关统一验证
