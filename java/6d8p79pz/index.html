cat nacos.conf
#HTTPS使用SSL访问的配置
server {
     #SSL 默认访问端口号为 443
     listen 443 ssl;

     #请填写绑定证书的域名
     server_name <你的域名>;

     #请填写证书文件的相对路径或绝对路径
     ssl_certificate /etc/letsencrypt/live/<你的域名>/fullchain.pem;

     #请填写私钥文件的相对路径或绝对路径
     ssl_certificate_key /etc/letsencrypt/live/<你的域名>/privkey.pem;

     #缓存SSL握手产生的参数和加密密钥的时长
     ssl_session_timeout 5m;

     #请按照以下协议配置
     ssl_protocols TLSv1.2 TLSv1.3;

     #请按照以下套件配置，配置加密套件，写法遵循 openssl 标准。
     ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:HIGH:!aNULL:!MD5:!RC4:!DHE;
     #ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE:ECDH:AES:HIGH:!NULL:!aNULL:!MD5:!ADH:!RC4;

     #加密套件优先选择服务器的加密套件
     ssl_prefer_server_ciphers on;

     # --- 安全头 ---
     add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
     add_header X-Content-Type-Options nosniff;
     add_header X-Frame-Options DENY;
     add_header Referrer-Policy "strict-origin-when-cross-origin";

     # --- 反向代理核心配置 ---
     location / {
        proxy_pass http://127.0.0.1:8080;  # 转发到 Nacos 容器

        # 传递原始请求信息
        proxy_set_header Host $http_host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;  # 告诉 Nacos 是 HTTPS
        proxy_set_header X-Forwarded-Ssl on;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_http_version 1.1;

        # 关键：禁用缓冲和缓存（GitLab 要求）
        proxy_cache off;
        proxy_request_buffering off;
        proxy_redirect off;

        # 超时设置（避免大文件上传失败）
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
    }
}
#HTTP 自动跳转 HTTPS 的安全配置
server {
     listen 80;

     #请填写绑定证书的域名
     server_name <你的域名>;

     # Let's Encrypt 验证路径（certbot 会自动处理）

     }

问题Caused by: com.mysql.cj.exceptions.UnableToConnectException: Public Key Retrieval is not allowed

如果启动的时候提示：Caused by: com.mysql.cj.exceptions.UnableToConnectException: Public Key Retrieval is not allowed。

我的环境是典型的 MySQL 8.x + Nacos 3.0.3 组合，触发了 MySQL 8 的默认认证机制问题。

MySQL 8 默认使用：caching_sha2_password而 JDBC 连接时如果没有允许“公钥获取”，就会直接报：Public Key Retrieval is not allowed

解决方案：在 JDBC URL 中允许公钥获取

给 Nacos 的 MySQL 连接 追加参数：

allowPublicKeyRetrieval=true
useSSL=false
serverTimezone=Asia/Shanghai

修改 docker-compose.yml 新增一行环境变量：

environment:
  - PREFER_HOST_MODE=hostname
  - MODE=standalone
  - SPRING_DATASOURCE_PLATFORM=mysql
  - MYSQL_SERVICE_HOST=mysql-server
  - MYSQL_SERVICE_PORT=3306
  - MYSQL_SERVICE_DB_NAME=nacos
  - MYSQL_SERVICE_USER=nacos
  - MYSQL_SERVICE_PASSWORD=your_nacos_db_password
  - MYSQL_SERVICE_DB_PARAM=allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=Asia/Shanghai

重点就是这一行：

- MYSQL_SERVICE_DB_PARAM=allowPublicKeyRetrieval=true&useSSL=false

Nacos 会自动拼成类似：

jdbc:mysql://mysql-server:3306/nacos?
allowPublicKeyRetrieval=true
&useSSL=false
&serverTimezone=Asia/Shanghai
